**섭니다.** 빈 자리에서 실제로 밟아 봤습니다:

```
1) 빈 자리에 s9 init   → 프로젝트 안 섬 + 「사용자를 먼저 등록하면 다음 init 에서 선다」
2) s9 user add hong    → 등록
3) 다시 s9 init        → 「기본 프로젝트 'general' — 프로젝트를 고르지 않은 새 문서가 여기 붙는다」
4) s9 project ls       → PRJ-20260908-001  (general)  [active]  기본 프로젝트  멤버:1/1
5) 첫 요청 접수         → project: general · project_source: default   ← 미정 없이 붙음
```

CONTEXT.md 앞머리도 원하신 대로입니다 — 「따로 정하지 않으면 문서가 여기로 옵니다」, **「프로젝트는 조직 단위가 아닙니다 — 혼자서도 용도마다 더 만들어 쓸 수 있습니다」**, 그리고 치는 명령 셋(만들기·이름 바꾸기·기본 옮기기).

한 가지만 아셔야 합니다: `s9-install` 이 사용자를 등록하지는 않아서, **진짜 새 설치는 2·3 을 사람이 손으로 밟습니다**. 화면 안내가 그 두 걸음을 이어 주고 있습니다.
