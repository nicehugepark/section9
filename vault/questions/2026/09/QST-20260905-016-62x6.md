## Original

설치 시 로그인 기능은 s9-install에 한거야 아니면 s9 code에 한거야? s9 code에서 되어야하는데

## Notes

### 2026-09-05T21:38:11+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-05 21:38:11 KST - lead]`

`s9-install` 쪽에만 했었습니다 — 맞는 지적이라 **`s9 code` 에 문을 세웠습니다**(commit `069c1a8` push).

- `s9 code` 는 훅 자가 점검 앞에서 로그인 흔적(`~/.claude/.credentials.json`, `CLAUDE_CONFIG_DIR` 존중)을 보고, 없으면 그 자리에서 **`claude auth login` 을 직접 돌립니다.** 로그인이 끝나면 「✓ 로그인 확인 — 계속한다」로 이어가고, 끝나지 않으면 「로그인이 끝나지 않았다 — `claude auth login` 뒤 다시 `s9 code`」로 세우고 들어가지 않습니다.
- 설치 끝의 안내와 doctor 의 「에이전트 로그인」 항목은 그대로 두었고, 하네스별 표(claude·codex·gemini)는 `s9`·doctor·install 세 벌이 같아야 한다는 시험(L1)과 문의 동작 시험(L3)으로 못박았습니다. 기본은 Claude 이되 다른 하네스의 갈래를 같은 표에서 이어 붙일 수 있습니다.

jade 에 새로 설치하실 때는 clone → `s9-install` → `s9 user attach nicehugepark`(두 번째 머신이라 동기화가 여기서 켜집니다) → `s9 code`(로그인이 없으면 여기서 로그인 화면이 뜹니다) 순서면 됩니다.
