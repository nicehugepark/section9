**아니오. 그 흐름에서는 안 붙습니다.** 방금 임시 자리에서 그대로 밟아 확인했습니다:

```
s9-install → s9 init (사용자 등록 없음) → 요청 접수
  결과: user: someone / project: (없음) / s9 project ls → 「프로젝트 없음」
```

`s9-install` 은 `s9 init` 을 부르지만 **사용자를 등록하지 않고**, 등록된 사용자가 없으면 기본 프로젝트도 서지 않습니다(아침에 고친 그 규칙 — init 이 신원을 지어내면 안 되므로). 그래서 `REQ-022` 가 세운 기본 프로젝트는 **사람이 `s9 user add` 를 치는 판에서만** 섭니다.
