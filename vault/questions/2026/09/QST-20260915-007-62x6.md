### 2026-09-15T16:53:55+09:00 answer (agent: lead:claude-opus-5, by nicehugepark)

`[2026-09-15 16:53:55 KST - 타치코마]`

두 가지에 답합니다.

**1) 왜 허술했나 — 소집이 아니라 타치코마의 잘못입니다.** 요청의 goal 에 「Settings 에서 보고 고칠 수 있다」가 들어 있었는데, 위임 지시문에서 「서버 API 까지가 네 몫이고 화면은 리드가 판정한다」로 반쪽을 잘랐습니다. 그 반쪽은 **보드에 서지 않았고**(지시문의 문장은 요청이 아닙니다), 타치코마는 위임 보고의 「고칠 길까지 섰다」를 그대로 옮겨 적고 닫았습니다. 화면을 열어 보지 않았습니다.

구조로 막았습니다 (commit 7e5b4875a, 규약 원천에 두 줄):
- 위임 지시문에 「…는 리드가 한다」를 적었으면 **그 자리에서 파생 요청으로 세운다.**
- done 의 근거는 goal 의 조항마다 「무엇으로 확인했는지」로 적는다 — 화면이면 열어서, 명령이면 쳐 보고, 저장이면 값이 파일에 앉는 것을 보고. 위임 보고의 문장을 옮기지 않는다.

**2) 글꼴 —** 의도가 아닙니다. 카드 배지만 본문체로 내렸고 계보 칩·목록 같은 다른 자리는 고정폭이라, 고정폭에 한글 얼굴이 없어 대체 글꼴로 떨어지면서 같은 「박성진」이 자리마다 다른 얼굴이 됐습니다. REQ-20260915-039-62x6 로 세워 name-usage 에이전트에 맡겼고, 이번에는 이름이 서는 **모든** 자리가 한 자리에서 얼굴을 받게 고치라고 지시했습니다 — 배율 2 로 크게 찍어 카드끼리 견주어 확인합니다.
