구체적으로 이렇게 했습니다.

**「메모리」는 Claude Code 자체의 기록 장치입니다** — section9 의 vault 가 아닙니다. 이 머신의 `~/.claude/projects/-home-sjpark1-section9/memory/` 아래에 사실 하나당 파일 하나를 두는 구조이고, 저는 거기에 `harness-agnostic.md`(1,348바이트: 내용·왜·어떻게 적용할지)를 쓰고, 세션마다 자동으로 읽히는 색인 `MEMORY.md` 에 한 줄을 더했습니다. 그러면 다음 Claude Code 세션이 이 프로젝트를 열 때 그 원칙이 제 문맥에 함께 실립니다.

다만 이것은 **이 머신·Claude 에서만 보이는 보조 기록**입니다 — GitHub 으로 동기화되지 않고, jade 에서도, Codex·Gemini 에서도 보이지 않습니다. 하네스 무관을 말씀하신 자리에 Claude 전용 기록만 남긴 것은 앞뒤가 안 맞아서, 방금 **규약에도 세웠습니다**: `harness/common/PROTOCOL.md` 에 0' 「하네스 무관」 조항(기본값은 Claude 이되 하네스에 기대는 자리 — 로그인 확인·훅·에이전트 스폰·메모리 — 는 하네스별로 갈리는 문 하나로 두고, 규약·지식은 이 저장소에 남긴다)을 넣고 `CLAUDE.md` 를 재생성해 commit `4ece075` 로 push 했습니다. 이제 어느 머신·어느 하네스에서 clone 해도 같은 글을 읽습니다. 메모리 쪽은 그 조항을 가리키는 보조로만 남깁니다.
