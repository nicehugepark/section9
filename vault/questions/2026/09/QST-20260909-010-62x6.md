## Original

docs 탭에서 질문 목록만 선택해서 질문을 보던 와중 graph 탭으로 오니까 전체 노드를 다 보게 되어있는데도 질문 노드들만 나타나는것 같다. 의도된건가? 문제인건가?

## Notes

### 2026-09-09T13:31:33+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-09 13:31:33 KST - 타치코마]`

**의도된 동작이지만, 화면이 그것을 말하지 않는 것이 문제입니다.** Docs 목록에서 「질문」만 고르면 헤더의 종류 필터가 question 으로 바뀌고(캡처의 헤더 오른쪽 select 가 「question」), 헤더 필터는 탭 공용이라 Graph 에도 그대로 걸립니다 — 그래서 「236 / 1514」만 그려집니다. 범례가 전부 켜져 있어 「전체를 보는데 질문만 나온다」로 읽히는 것이 결함입니다. REQ-066 으로 받아, Graph 가 헤더 종류 조건이 걸려 있음을 한 줄로 말하고 지우는 손잡이를 두게 합니다(범례를 켰는데 안 보일 때 이미 쓰는 그 줄). 지금은 헤더의 종류 select 를 「전체」로 돌리면 다 보입니다.
