답(채팅 13:0x): 「동기화 · 치워 둔 작업 — 동기화가 잠시 치워 둔 2건이 아직 남아 있습니다 · 4일째」는 맥의 sync 가 pull --rebase --autostash 를 하며 그때 commit 되지 않은 변경을 잠시 git stash 에 치워 두었다가 되돌려 놓지 못한 것이 2건, 가장 오래된 것이 9월 11일부터라는 뜻이다(bin/s9.py _sync_autostash_left: git stash list 의 autostash 항목 수와 가장 오래된 시각). 동기화 자체는 지금 막혀 있지 않다 — 그 2건은 맥에서 그날 편집하고 commit 되지 않은 내용의 사본이라, 안에 무엇이 있는지 보고 되살릴지 버릴지 정해야 한다. 되살리기·패치로 보관은 맥 세션이 할 수 있고, 버리기(git stash drop/clear)는 s9-git-gate 가 사람의 OK(S9_GIT_OK=1)를 요구한다. 이 컴퓨터의 같은 잔재 8건은 9월 14일 patch 로 보관한 뒤 주인이 지웠다(REQ-20260914-005-62x6). 알림 줄의 × 는 이 브라우저에서 숨길 뿐 사실을 지우지 않는다.
