## Original

그럼 새로 설치할 때 git user, email을 입력받게 하는건가?

## Notes

### 2026-09-21T13:19:16+09:00 answer (agent: lead:claude-opus-5, by nicehugepark)

`[2026-09-21 13:19:16 KST - 타치코마]`

**아니요, 묻지 않습니다.** 그리고 그 물음 덕에 구멍 하나를 찾아 방금 고쳤습니다(commit `3a2b771ac`).

**설치 흐름**

1. 배포판을 풀고 `bin/s9 code` — 훅·스킬·역할 에이전트를 설치하고 저장소를 세웁니다
2. **묻는 것은 셋뿐입니다: id(폴더 이름, 영문) · 성 · 이름.** git user/email 은 묻지 않습니다
3. 신원은 사다리가 스스로 고릅니다 — 프로필 메일 → `<github>@users.noreply.github.com` → 임시값
4. 대시보드가 뜨고 Claude Code 가 열립니다

**그래서 완전히 새로 설치한 사람은 임시값으로 돕니다** — 3번의 첫 두 칸에 쓸 재료가 프로필에 아직 없기 때문입니다. `s9 doctor` 가 「지금은 section9 이 임시로 지은 이름으로 기록하고 있습니다」로 알리고, 나중에 Settings 에서 github 를 적으면 그때 올라섭니다.

**그 「그때 올라선다」가 안 되고 있었습니다.** 재평가가 `s9 user add`·`attach` 두 자리에만 붙어 있어서, Settings 로 적은 사람은 임시 이름 그대로였습니다. 프로필을 고치는 자리는 `do_user_update` 하나이고 대시보드도 CLI 도 그것을 지나므로, 거기 붙여서 모든 길을 함께 풀었습니다.

묻지 않는 것이 옳은지는 product-owner 의 판정이었습니다 — 문서가 바뀔 때마다 commit 하는 제품이라 신원 부재는 곧 저장 불능이고, 첫 화면에서 사람을 세우면 거기서 끝납니다. 대신 **고쳐야 할 때만** 말합니다.
