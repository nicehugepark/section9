**지금까지는 본문이 주입되지 않았습니다.** 닿는 자리가 둘뿐이었습니다. ① 세션 시작 훅이 `s9 digest` 를 실어 주는데, 거기에는 「## 내 프로젝트 컨텍스트 (작업 전 Read) — section9: projects/section9/CONTEXT.md」라는 **경로 한 줄**만 섭니다(DOC-20260824-001 의 1단계 — "경로만, 내용 주입은 3단계" 라고 코드 주석에 적혀 있고 3단계는 안 만들어져 있었습니다). ② 요청을 프로젝트에 붙일 때(`s9 new request --project`) CLI 가 「↳ 프로젝트 컨텍스트: … 작업 전 Read하라」와 **앞 5줄**을 찍습니다. 즉 리드가 규약대로 Read 해야만 본문이 문맥에 들어오고, 안 읽은 세션은 모릅니다. 조금 전 push 정책을 그 파일에 적은 것은 그래서 반쪽이었습니다.

**그래서 3단계를 세웠습니다(REQ-20260905-020-62x6).** `s9 digest` 가 내 프로젝트의 CONTEXT.md **앞 30줄을 본문으로** 싣습니다 — 어느 하네스든 세션 시작에 digest 를 실으면 같은 것을 봅니다. 전체 주입은 하지 않고 상한을 넘기면 「나머지는 Read」라고 말하며, 예산이 모자라면 이 절이 먼저 줄어듭니다. 실측으로 이 저장소의 digest 에 「저장소 정책 — push 는 main 으로 직접」이 실리는 것을 확인했고 시험 1건을 붙였습니다.
