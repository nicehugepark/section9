blocked 요청은 어떻게 해야하나?

### 2026-09-08T19:12:35+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-08 19:12:35 KST - 타치코마]`

blocked 는 「에이전트가 더 할 수 없고 사람의 결정이나 실행이 있어야 풀리는 자리」입니다 — 카드의 사유에 **여는 조건**이 적혀 있고, 그 조건을 채운 뒤 상태를 옮기면 됩니다. 지금 blocked 는 둘입니다.

**REQ-20260908-040-62x6 코드와 문서를 가른다** — 결정 대기 (14:22 「아니 하지마 더 고민해보고」).
- 여는 조건: 저장소를 가를지, 가른다면 언제 할지 정하는 것.
- 하실 일: 대시보드에서 카드를 열고 — 가르기로 하면 `in-progress` 로 옮기고(리드가 이어받습니다), 안 하기로 하면 `cancelled` 로 옮깁니다. 아직 결정이 안 섰으면 그대로 두셔도 됩니다 — blocked 는 방치가 아니라 대기입니다.

**REQ-20260908-041-62x6 다른 WSL 머신에 설치** — 실행 대기.
- 여는 조건: 그 머신에서 만든 요청 문서가 GitHub section9-test 에 보이는 것.
- 하실 일 (그 머신에서):
  ```
  cd <section9-test 클론 디렉토리>
  git pull                 # commit 3475f502 이후 코드를 받았으면 아래 한 줄은 필요 없습니다
  bin/s9 sync --on         # 「바깥과 오갑니다 — 문서 이벤트마다 commit→pull→push」가 나오면 된 것
  bin/s9 new request --title '연결 확인' --summary '동기화 확인' --goal 'GitHub 에 보인다' --size S
  ```
  GitHub 의 section9-test 에 그 요청 문서가 올라오면 카드를 `done` 으로 옮기시면 됩니다. 안 올라오면 그 화면의 오류 줄을 채팅에 붙여 주시면 타치코마가 이어받습니다. (origin 이 ssh 주소라 그 머신에 GitHub ssh 키가 있어야 합니다.)
