open 상태의 요청들도 같이 챙기도록 해. 순서를 기다리는 중인건가?

`[2026-09-08 21:55:39 KST - 타치코마]`

기다리는 것이 아니라 **의존 순서대로 하나씩 닫고 있습니다** — 지금까지 071(연동 확인)·072(프로젝트 연동 설정)·080(외부 서비스 묶음)이 done 이고, 방금 073(요청→Jira 이슈 생성)에 착수했습니다.

- 071 `s9 jira ping` — 실제 Jira 로 확인했습니다: 「연동됐습니다 — Seongjin Park」. Settings 판의 「연동 확인」 버튼도 같은 길입니다.
- 072 — 넷째 항목(프로젝트 연동)은 지금 터미널로 채울 수 있습니다:
  ```
  cd ~/section9
  bin/s9 project add mp1 --name 'Jira 시험'          # 시험용 프로젝트(이 저장소는 내보내지 않는다는 결정)
  bin/s9 project jira mp1 set --site https://nicehugepark.atlassian.net --key MP1
  ```
  → Settings › 외부 서비스가 「준비 4/4」가 됩니다. 기본값은 direction push · export_origin human(사람이 직접 만든 요청만)입니다.
- 080 — Settings 목록에서 Jira 가 「외부 서비스 · Jira · 준비 3/4」 아래로 들어갔습니다(tech-writer 판정: 「외부 시스템 연동」은 「시스템」과 겹쳐 반려).

남은 open 은 넷이고 순서는 073 → 074(카드·문서 표시)·075(상태 push) → 076(상태 pull), 그 사이에 독립인 077(작업자 옵트인)·078(가이드)을 끼웁니다. 073 이 끝나면 mp1 프로젝트에서 요청 하나를 만들어 MP1 보드에 이슈가 서는지 함께 보실 수 있습니다.
