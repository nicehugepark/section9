## Original

s9 instance init 어떻게 만들었다는거지? example 이 아니고 section9-test로 만들고 싶었는데.. 그래서 example 디렉토리이름을 section9-test로 바꾸고 깃헙에 section9-test 라는 private 리포를 만들었다. 이제 뭘 해야하나?

### 2026-09-08T14:57:47+09:00 answer (agent: lead:claude-opus-5, by nicehugepark)

`[2026-09-08 14:57:47 KST - 타치코마]`

**push 했습니다.** `git@github.com:nicehugepark/section9-test.git` 에 올라갔습니다(`main`, 1커밋).

이름은 제 잘못입니다 — 앞서 말씀에서 「example」을 예로 드셨길래 그 이름으로 `s9 instance init git@github.com:nicehugepark/example.git --dir ~/example` 를 돌렸습니다. 물어봤어야 했습니다. 지금 `origin` 을 `section9-test` 로 고쳐 두었습니다.

**이제 다른 WSL 머신에서** — 이 세 줄입니다:

```bash
git clone git@github.com:nicehugepark/section9-test.git ~/section9-test
cd ~/section9-test && bin/s9-install
bin/s9 code
```

첫 실행에서 이름을 물으면 원하시는 이름을 치십시오(그 저장소의 첫 사용자가 됩니다). 등록되는 순간 **기본 프로젝트가 그 자리에서 섭니다.**

**확인하실 것 셋**
- `bin/s9 ls` 가 비어 있다 (section9 문서가 하나도 없다)
- 요청 하나를 만들면 `project: general` 로 붙는다
- 이쪽 section9 대시보드에는 **아무것도 안 뜬다**

`~/section9-test` 는 이 머신에도 그대로 있으니, 원하시면 여기서도 `cd ~/section9-test && bin/s9 code` 로 열어 볼 수 있습니다(대시보드 포트는 9911 로 잡혀 있어 9909 와 겹치지 않습니다).
