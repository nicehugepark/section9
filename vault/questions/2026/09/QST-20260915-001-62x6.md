**됩니다.** 저작권자는 주인이니 어떤 조건으로든 허가할 수 있고, 「비상업 목적만 허가, 영리 목적은 저작권자의 별도 허가」가 바로 그 꼴입니다. 지금까지는 LICENSE 가 없어 법적으로는 「모든 권리 유보」— 아무도 어떤 사용도 허가받지 않은 상태였습니다.

**초안을 담아 review 에 올렸습니다(REQ-20260915-002-62x6).** 표준 문안인 PolyForm Noncommercial 1.0.0 을 원문 그대로 LICENSE 에 넣고 맨 위에 저작권 고지(Seongjin Park, nicehugepark)를 붙였으며, README 에 라이선스 절을 더했습니다. 배포판 tar.gz·zip 에도 함께 실립니다. 뜻은 이렇습니다.

- 개인·비영리 단체·연구·교육 같은 비상업 목적은 자유롭게 쓰고 고치고 나눌 수 있습니다.
- 회사가 업무에 쓰는 것을 포함해 영리 목적의 사용은 금지이고, 주인이 개별로 상업 허가를 줄 수 있습니다.
- 이 라이선스는 오픈소스(OSI) 정의에는 들지 않습니다. 「소스 공개, 비상업 한정」이 정확한 이름입니다.

**아셔야 할 것 둘.**

- 이미 받아 간 사람에게는 소급되지 않습니다. 0.9.0·0.9.1 배포판에는 LICENSE 가 없었고, 그 상태는 오히려 더 엄격한 「권리 유보」였습니다.
- 다른 사람의 기여를 받게 되면 그 기여분의 저작권은 그 사람에게 있어, 주인만 상업 허가를 줄 수 있으려면 기여자 계약(CLA)이 필요합니다. README 에 그 뜻을 한 줄 적어 두었고, 저장소가 공개되면 정식 CLA 를 세우겠습니다.

GitHub 저장소 첫 화면에서 LICENSE 를 열어 보시고 이 문안이면 승인, 일정 기간 뒤 오픈소스로 바뀌는 BSL 같은 다른 꼴이나 다른 저작권 표기를 원하시면 적어 반려해 주십시오. 타치코마는 변호사가 아니니, 회사 상대로 실제 분쟁이 예상되면 문안을 변호사에게 한 번 보이는 것이 맞습니다.
