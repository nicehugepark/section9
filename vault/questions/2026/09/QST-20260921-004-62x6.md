**네, `bin/s9 code` 하나면 됩니다.** 실제로 clone 해서 돌려 보고 답합니다 — 훅·스킬 13개·역할 에이전트 30여 개를 자기가 먼저 설치하고, git hook 과 merge driver 를 걸고, 대시보드를 띄운 뒤 claude 를 실행합니다. 따로 `s9-install` 을 칠 필요가 없습니다.

다만 그 머신에서 **먼저 해 두어야 할 것 셋**이 있습니다. `s9 doctor` 가 그 자리에서 셋 다 잡아 줍니다:

1. **git 이름** — 새 WSL 이면 비어 있고, 그러면 commit 이 아예 거부됩니다(`✗ git 이름: 이 컴퓨터의 git 이 누구로 commit 할지 정해지지 않았다`). 어제 맥미니에서 났던 그 자리입니다.
   ```
   git config --global user.name <이름>
   git config --global user.email <메일>
   ```
2. **claude 로그인** — `△ claude 설치됨 · 로그인 없음`. 터미널에서 `claude` 를 한 번 띄워 `/login` 하면 됩니다.
3. **계정 이름 잇기** — 그 머신의 리눅스 계정 이름이 `nicehugepark` 가 아니면 첫 실행이 등록을 물어봅니다. 같은 사람으로 이으려면 `s9 user add` 가 아니라 **`s9 user attach nicehugepark`** 입니다 — `add` 로 하면 별개 사람이 됩니다.

한 가지 더: clone 한 상태에서는 `.s9-sync` 가 없어 **동기화가 꺼져 있습니다**(`✓ 동기화: 인스턴스가 아니다 — git 쓰기 없음`). 그 머신의 문서를 section9-cloit 으로 올리려면 대시보드의 Settings › 저장소에서 켜야 합니다.
