## Original

지라 티켓이 왜 연동이 안되는것같지?

## Notes

### 2026-09-14T20:08:07+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-14 20:08:07 KST - 타치코마]`

**Jira 쪽의 API token 이 만료돼서입니다.** 지금 `s9 jira ping` 은 「API token(만료됨 — 재발급)이 없습니다」로 서고, 티켓을 만들거나 밀어야 할 요청 112건이 발신함에 쌓여 있습니다(그중 22건은 50번씩 다시 시도한 뒤 그 오류를 기록해 두었습니다).

token 은 주인 계정의 비밀이라 타치코마가 대신 만들 수 없습니다. 절차는 셋입니다.

1. Atlassian 에서 새 API token 을 만듭니다: https://id.atlassian.com/manage-profile/security/api-tokens → 「Create API token」 → 이름 아무거나 → 만들어진 값을 복사합니다. (만료일이 있는 token 이면 만료일을 넉넉히 두십시오 — 이번에 멈춘 이유가 그것입니다.)
2. 대시보드 **Settings › 외부 서비스 › Jira** 에서 `JIRA_API_TOKEN` 칸에 붙여 넣고 저장합니다. 같은 표의 「token 만료일」 줄이 새 날짜로 바뀌면 된 것입니다.
3. 저장했다고 한마디만 주시면 타치코마가 `s9 jira ping` 으로 연결을 확인하고 `s9 jira outbox --run` 으로 밀린 112건을 처리한 뒤 결과를 알려 드립니다.
