### 2026-09-05T21:39:25+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-05 21:39:25 KST - lead]`

코드 순서 그대로입니다.

**`bin/s9-install`** — 묻는 것 없이 위에서 아래로 내려가며 한 줄씩 찍습니다.
1. `dirs OK: <저장소>` — state/·index/ 등 자리 만들기
2. `git hooks OK: post-merge, post-checkout, pre-commit(guard), post-commit(기록)` · `merge driver OK: merge.s9doc → s9 merge-doc` (git 저장소가 아니면 「git hooks 생략」)
3. `claude hooks 갱신됨: ~/.claude/settings.json …` 또는 `claude hooks 최신 상태` — `--no-claude` 면 건너뜀
4. `agents/skills 설치·검증 OK (N개 에이전트 유효)` — 스킬·역할 에이전트를 `~/.claude/` 에 링크
5. 다른 하네스(gemini·codex)가 설치돼 있으면 그 규약 블록 갱신, 없으면 `미설치 감지 — 생략`
6. `section9 install 완료`
7. **로그인 확인** — `로그인 확인: claude` / `claude 는 설치됐지만 로그인이 없다 — 터미널에서 claude 를 한 번 띄워 /login … 그다음 s9 code` / 에이전트 CLI 자체가 없으면 그 안내. 여기서는 말만 하고 멈추지 않습니다.
8. 대시보드가 안 떠 있으면 `대시보드 기동: http://127.0.0.1:9909/ (감시 포함)`, 떠 있으면 `대시보드 이미 실행 중`.

**`s9 code`** — 여기가 문입니다.
1. 포트 판정 — 9909 에 남의 section9·다른 프로그램이 있으면 `포트 9909 는 … — 9910 로 띄운다`
2. `대시보드 실행 중: …` 또는 `대시보드 기동: …`
3. **로그인 문** — 흔적이 없으면 `◌ Claude Code 로그인이 없다 — 먼저 로그인한다 (claude auth login)…` 하고 그 자리에서 로그인 화면이 뜹니다. 끝나면 `✓ 로그인 확인 — 계속한다`, 안 끝나면 `Claude Code 로그인이 끝나지 않았다 — claude auth login 뒤 다시 s9 code` 로 멈춥니다.
4. 훅 자가 점검 — 없으면 `◌ section9 훅 미설치 감지 — s9-install 을 먼저 실행한다…` → 위 설치 절차가 안에서 돌고 `◌ 설치 완료 — 지금 시작하는 세션부터 자동 audit이 적용된다.`
5. 사용자 확인 — 미등록이면 `◌ 미등록 사용자(<계정>) — 등록하려면: s9 user add <이름>` (두 번째 머신이면 add 가 아니라 `s9 user attach <이름>`)
6. claude 자동 업그레이드 시도(실패 무해) → **이 터미널에서 Claude Code 실행**, 첫 프롬프트로 세션 기동 줄이 들어가 수신함을 arm 하고 `s9 next` 로 이어받을 일을 집습니다.
