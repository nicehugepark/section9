### 2026-09-06T11:56:55+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-06 11:56:55 KST - 타치코마]`

요청으로 세워(REQ-20260906-049-62x6) architect 에게 부딪히는 자리의 표를 30분 안에 세우게 했습니다. 타치코마가 먼저 확인한 것 셋입니다.

- **문서 번호 충돌은 없습니다.** 문서 id 의 꼬리(이 기계는 `62x6`)는 `sha1(hostname|HOME)` 에서 나오는데 WSL(`/home/…`)과 윈도우 네이티브(`C:\Users\…`)는 HOME 이 달라 꼬리가 다릅니다. 그 값을 고정해 두는 파일(`users/<이름>/config/local.json`)은 git 에 실리지 않아 clone 끼리 섞이지 않습니다.
- **대시보드 포트는 부딪힙니다.** WSL 의 9909 는 윈도우 중계로 윈도우의 localhost 에도 공개되므로, 윈도우 네이티브가 먼저 9909 를 쥐면 WSL 쪽 `s9 code` 는 「남의 것」으로 보고 9910 으로 옮겨야 합니다 — 그 판정이 오늘 고친 자리(root 없는 응답 처리)를 포함해 제대로 도는지가 검증 대상입니다.
- **같은 clone 을 /mnt/c 로 공유하는 것은 위험합니다.** `state/`(포트·세션·잠금·커밋 진행 표식)가 하나로 겹치고, 윈도우에는 파일 잠금(fcntl)이 없어 감시자 중복을 못 막습니다. 이 방식은 막거나 문서로 금지해야 할 가능성이 큽니다.

표가 오면 고칠 것(코드)·문서화만 할 것을 갈라 고치고, `docs/11-windows.md` 와 가이드에 「함께 쓰기」 절을 넣습니다. 046·042 도 진행 중입니다.
