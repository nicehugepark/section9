**말씀하신 구멍이 실제로 있습니다 — 고치겠습니다** (`REQ-20260921-003-62x6`, 착수했습니다).

**① git 설정 없이도 도는가 — 두 길은 되고, 한 길이 빠졌습니다.**

임시 신원(`s9 <계정>` / `<계정>@local`)을 저장소 로컬에 박는 함수가 있습니다. 부르는 자리가 둘뿐입니다:
- 배포판을 풀고 첫 실행 → 저장소를 세우면서 박습니다. **됩니다.**
- 초대 링크로 팀 저장소에 잇기(`s9 code --join`) → 같은 함수를 부릅니다. **됩니다.**
- **`git clone` 해서 그 자리에서 `s9 code`** → `.git` 이 이미 있어 첫 갈래가 「이미 저장소」로 빠지고, `--join` 도 아니라 **어느 쪽도 안 탑니다.** 신원이 빈 채로 남고, 문서가 바뀔 때마다 도는 로컬 commit 이 거부됩니다.

조금 전 section9-cloit 을 clone 해서 돌려 봤을 때 나온 `✗ git 이름` 이 정확히 이 자리입니다.

**② 연동할 때 git 정보를 참조하는가 — 참조합니다.**

첫 실행이 `user.name`·`user.email` 을 읽어, 등록된 사람과 같으면 **이름을 묻지 않고** 그 사람으로 잇습니다. 초대로 들어올 때는 `user.email` 이 초대받은 주소와 같으면 멤버 자리가 그 사람 이름으로 바뀝니다.

다만 **반대 방향은 없습니다** — section9 이 아는 사람 정보로 git 의 `user.name`/`user.email` 을 채워 주지는 않습니다. ① 의 구멍에 빠지면 사람이 손으로 쳐야 합니다.

고칠 것은 ① 입니다. clone 으로 온 자리도 신원을 세우게 하겠습니다.
