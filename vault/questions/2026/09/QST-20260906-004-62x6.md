## Original

jade의 9909는 내가 임대에서 사용하는 나(sjpark, jade 머신의 linux user)가 아니라 jade의 section9이 이미 점유한 포트다. 그럼 나는 무슨 포트를 써야하나? 참고로 jade의 section9 대시보드는 지금 내 브라우저에서 9919로 잘 뜨는 중이다.

## Notes

### 2026-09-06T00:54:40+09:00 answer (agent: lead:claude-fable-5-1, by nicehugepark)

`[2026-09-06 00:54:40 KST - lead]`

확인했습니다 — jade 에서 9909 를 쥔 것은 리눅스 사용자 `jade` 의 `/home/jade/repo/section9`(어제 11:54 에 뜬 옛 판)이고, 당신(`sjpark`)의 `s9 code` 는 **자기 대시보드를 띄우지 못한 채** 그 서버를 자기 것으로 오인하고 있습니다(`~/section9/state/port` 없음, 감시자만 9909 를 지킴). 원래 9909 가 남의 것이면 9910~9949 로 자동으로 옮겨 적어야 하는데, 옛 판의 응답에 `root` 가 없어 「내 것」으로 읽은 것이 원인입니다 — 결함으로 등록했고(REQ-20260906-002-62x6, 001 의 자식) 바로 잡겠습니다.

**지금 쓰실 포트: 9910** — 사람이 못박은 값은 하네스가 옮기지 않습니다.

1. jade 의 ssh 터미널에서 지금 도는 `s9 code` 를 끝냅니다(그 클로드 세션에서 `/exit` 또는 Ctrl+C 두 번).
2. 같은 터미널에서 포트를 못박고 다시 띄웁니다:
   ```
   cd ~/section9 && echo 9910 > state/port && ./bin/s9 code
   ```
   — 기동 문구에 9910 이 보이면 됩니다. (한 번만 하면 이후 `./bin/s9 code` 만 쳐도 9910 을 따릅니다.)
3. 이 기계의 터널 터미널에서 Ctrl+C 로 끊고, 목적지만 9910 으로 바꿔 다시:
   ```
   ~/section9/bin/s9 secret run -- sh -c '{{secret:jade}} -4 -N -L 127.0.0.1:9919:127.0.0.1:9910'
   ```
4. 브라우저 `http://127.0.0.1:9919` 새로고침 — 지금 보이는 것(jade 사용자의 옛 대시보드)이 아니라 당신의 세션이 뜨는 대시보드가 보이면 맞습니다.

하지 말 것: jade 사용자의 9909 서버는 남의 것이니 세우지 마십시오.
