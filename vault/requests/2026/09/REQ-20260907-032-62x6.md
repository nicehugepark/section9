### 2026-09-07T14:01:47+09:00 response (agent: sub:ux-writer, by nicehugepark)

「SaaS 블루」가 뜻 없는 말인 게 맞았습니다. 열 개 스킨 중 여섯(슬레이트·코발트·필드·코르크·그리드·모노)이 값을 그대로 음차한 이름이었고, 설명은 만드는 사람의 말(앱 셸·플랫 패널·레이어·블러·인버스·뉴트럴·웜 그레이·CRT)이라 고르는 데 아무 도움이 안 됐습니다. 이름과 설명만 고쳤고 **값 16개는 그대로**입니다 — `s9 user config ui_skin ledger` 는 계속 통합니다.

### 전 / 후

skin — 「디자인 언어」 → 「모양과 배치」
| 값 | 전 | 후 |
|---|---|---|
| ledger | 장부 — 선으로 나눈 계기판 | 선 — 선으로만 나눈 각진 화면 |
| calm | 여백과 카드 — 떠 있는 카드, 넓은 여백 | 카드 — 넓은 여백에 둥근 카드가 떠 있다 |
| soft | 사이드바 — 좌측 세로 탭 앱 셸 | 왼쪽 메뉴 — 탭이 왼쪽 세로줄에 선다 |
| glass | 유리 — 반투명 레이어와 블러 | 반투명 — 판이 비치고 뒤가 흐려진다 |
| terminal | 모노 — 전면 고정폭, 인버스 강조 | 고정폭 글꼴 — 고르면 흑백이 뒤집힌다 |
| grid | 그리드 — 고밀도 표형 배치 | 표 — 여백 없이 끝까지 채운 촘촘한 표 |
| slate | 슬레이트 — 밝은 SaaS 블루 | 회청 바탕 — 흰 판이 얹히고 강조는 파랑 |
| cobalt | 코발트 — 짙은 헤더 밴드 | 남색 띠 — 맨 위 띠만 짙고 아래는 밝다 |
| field | 필드 — 컬러 배경에 플랫 패널 | 색 바탕 — 색이 크게 번지고 판은 납작하다 |
| cork | 코르크 — 컬러 보드 위 카드 | 보드 — 옅은 색 바탕에 회색 칸과 흰 카드 |

tone — 「색」(그대로). 여섯 다 「밝다/어둡다 + 바탕의 색기 + 강조색」을 말하게 했습니다.
| 값 | 전 | 후 |
|---|---|---|
| system | 자동 — OS 설정 따라감 | 자동 — 컴퓨터 설정을 따라감 |
| paper | 종이 — 밝은 웜 그레이 | 종이 — 밝음. 노란기 도는 바탕, 강조 검정 |
| mist | 안개 — 밝은 회청, 파랑 강조 | 회청 — 밝음. 푸른기 도는 바탕, 강조 파랑 |
| carbon | 카본 — 어두운 뉴트럴 | 검정 — 어두움. 색기 없는 바탕에 흰 강조 |
| graphite | 그래파이트 — 어두운 청회색 | 짙은 회청 — 어두움. 푸른기 도는 바탕 |
| phosphor | 인광 — CRT 그린 | 초록 — 어두움. 검은 바탕에 초록 글자 |

density — 「밀도」 → 「여백」 (그 축이 실제로 바꾸는 것). normal 「표준 여백」 → 「글자와 여백이 기본 크기」, compact 「여백을 줄여 더 많이」 → 「…더 많이 담는다」(서술어 없는 문장 제거).
판 아래 안내문의 「세 축은 자유롭게 조합되고」도 「셋은 마음대로 섞어 쓸 수 있고」로 바꿨습니다.
