## Original

실제 사고 2026-09-15: REQ-20260915-012-62x6 의 마지막 단계(맥의 autostash 2건 비우기)가 끝내 사람 손을 기다렸다. 문이 둘이라서다 — ① `S9_GIT_OK=1 git stash drop …` 은 하네스의 자동 승인 분류기가 「Auto-Mode Bypass」로 거부한다(명령 앞의 환경변수), ② `git stash drop …` 은 s9-git-gate 가 거부한다(그 환경변수를 요구). 설치가 깔아 주는 승인 규칙(REQ-20260915-006-2n7g)은 ①의 꼴에 맞지 않으므로 이 조합은 규칙으로는 열리지 않는다. 옮길 자리: bin/s9 에 stash 명령을 세우고 s9-git-gate 는 제 명령을 그대로 통과시킨다. drop 은 그 보관함의 patch 가 vault 의 어느 요청에 담겨 있는지 확인한 뒤에만 지우고, 없으면 state/sync-rescue/ 에 먼저 뽑는다 — 사람의 확인 대신 「잃지 않았다」는 증거가 조건이 된다.
