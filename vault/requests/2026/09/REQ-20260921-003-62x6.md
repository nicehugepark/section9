## Original

주인 물음 2026-09-21 10:04: 「어차피 처음부터 깃 연동은 안되어 있을거아냐. 그러면 깃 설정이 없어도 되긴 해야할텐데.. 그리고 깃 연동할 때 깃 정보를 참조할 수 있게끔 해야하지 않나? 지금 그렇게 되어 있어? 어떻게 되어있어?」

실측(2026-09-21, section9-cloit 을 clone 해 확인): 임시 신원(s9 <계정> / <계정>@local)을 박는 _ensure_identity 는 두 자리에서만 불린다 — ensure_repo(저장소를 새로 세울 때)와 join_repo(초대 링크로 팀 저장소에 이을 때). git clone 으로 온 자리는 .git 이 이미 있어 ensure_repo 가 skipped=repo 로 빠지고, --join 도 아니라 어느 갈래도 타지 않는다. 그 결과 s9 doctor 가 「✗ git 이름: 이 컴퓨터의 git 이 누구로 commit 할지 정해지지 않았다 — commit 이 거부된다」를 낸다.
