### 5. 여러 건일 때 — 한 줄만 펼치고 나머지는 셉니다

| 건수 | 보이는 것 |
|---|---|
| 0 | 줄이 없습니다 (테두리·여백 0) |
| 1 | 그 한 건 |
| 2 이상 | 가장 위 한 건 + `▸ N건 더 보기` |

- 기본이 접힘인 이유: 한 화면 한 결정. 가장 급한 것 하나를 온전히 읽히게 합니다.
- 줄 전체 높이 상한 `max-height:30vh` + `overflow-y:auto` — 머리가 화면을 먹는 것을
  기하로 막습니다.

**순서** — 세 열쇠를 차례로 적용합니다.
1. 심각도 (막힘 > 주의 > 정보)
2. 여는 길이 있는 것 먼저 (할 일이 있는 것이 위)
3. 오래 서 있던 것 먼저 (새것이 위로 오면 보던 줄이 매번 밀립니다)

### 6. 닫기의 뜻 — 조건 지문(sig)

알림마다 **서버가** 그 알림을 참으로 만든 사실에서 지문을 만듭니다
(`jira:expiry:<만료일>` · `oldcode:<기동시각>` · `github:supplies:<채운 수>`).
닫으면 `localStorage` 한 열쇠(`s9notice_ack`)에 `{알림id: 지문}` 으로 적히고,
**지문이 달라지면 다시 나타납니다** — 곧 조건이 바뀔 때까지 안 뜹니다.

이것은 새 장치가 아닙니다. 지금 `s9oldcode_ack`(기동시각)과 `s9guard_ack`(사건 시각)이
이미 같은 일을 따로따로 하고 있습니다. 이름과 자리를 하나로 모을 뿐입니다.

**되돌리기**: 살아 있는 알림이 하나라도 있으면 줄 끝에 `닫아 둔 것 N` 을 셉니다.
전부 닫혔으면 줄째 사라집니다(빈 띠 금지). 언제든 되돌리는 자리는 Settings 안의
한 줄 — `닫아 둔 알림 3건 [전부 되돌리기]`, 0건이면 그 줄도 없습니다.

**대안 A — 종 아이콘 + 수 + 펼침 판.** 머리 높이가 절대 안 늘고 알림이 몇이든

**대안 B — 각 판 안에 두기**(Jira 는 Settings 안, GitHub 는 저장소 판 안). 고치는
자리에서 말하니 문맥이 가장 가깝습니다. 그러나 **보러 가야 보입니다** — Settings 를

머리로 올렸습니다. **부결하되 버리지 않습니다**: 머리의 알림은 「있다」를, 판 안의
준비물 표는 「무엇을 채우나」를 맡아 층이 갈립니다.

**채택 — 대안 C**: 머리 아래 한 줄 + 제자리 펼침. 0건이면 자리가 없고, 1건이면

### /api/notices 계약 (backend-developer, 구현 완료 · commit 대기)

`GET /api/notices` → `{"notices": [건, …]}` · `/api/boot` 의 `notices` 조각도 같은 값(같은 함수 notices_info). 정렬은 서버가 한다: halt → warn → note, 같은 등급은 since 오래된 것 먼저.

한 건: `{id, sev, source, say, go, since, sig, title, body, note}`
- `id` 알림 종류의 고정 키 — `jira:block` · `jira:expiry` · `identity:unreg` · `server:oldcode` · `sync:fail` · `sync:autostash`. 닫기 저장은 `{id: sig}` 로.
- `sev` `halt`(막힘) · `warn`(주의) · `note`(정보). 이번에 서버가 싣는 것은 halt·warn 뿐(정보 등급은 전부 화면이 아는 진행 칩).
- `source` 주체(값): `Jira` · `서버` · `동기화` · `이 컴퓨터`(미등록 계정, designer 9절 ②).
- `say` = `title + " — " + body` (translator 최종 표 그대로, 값 자리만 채움). `title`·`body` 도 따로 준다. `note` 는 딸림 한 줄(툴팁, 없으면 "").
- `go` 하나: 화면 안 자리 `{"kind":"screen","label":"외부 서비스 › Jira 열기","target":"settings:external:jira","act":"준비물 채우기"}` — target 은 `settings:<왼쪽 목록 id>[:<절>]`(왼쪽 목록 id 는 settings.js SECTIONS 의 external·repo, 절 jira 는 jiraPanelHTML 의 「Jira」 머리·#j-summary, 절 smtp 는 「이메일 보내기」·#s-summary). 명령은 `{"kind":"cmd","text":"s9 user add <계정>"}`(라벨 「명령 복사」는 화면 상수).
