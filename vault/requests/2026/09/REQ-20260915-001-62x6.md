REQ-20260915-001-62x6 「대시보드 알림 체계 설계」로 세우고 넷을 소집했습니다. 지금 병렬로 갑니다.

- **designer** — 외부 서비스·시스템 알림이 서는 하나의 자리를 설계합니다. 어디에 서나(「옛 코드」 띠와 어긋나지 않게), 알림 한 건의 꼴(심각도·무엇이·여는 길·언제부터·닫기), 여러 건일 때와 좁은 폭(400px), 열 스킨 × 밝은·어두운 tone 에서 심각도 셋이 갈려 보이는 규칙, 알림이 없을 때는 흔적이 없을 것. 시안을 캡처로 붙입니다.
- **ux-writer** — 알림 문구의 형식(제목·본문·행동)과 열 가지 알림의 초안. 서비스 이름은 값 자리로 두어 Jira 전용 문장이 되지 않게 합니다.
- **tech-writer** — 낱말마다 그대로 둘 것(token·push·autostash)과 옮길 것을 판정합니다.
- **translator** — 판정대로 사람들이 쓰는 어휘로 옮긴 최종 문구 표를 냅니다.

옮겨 갈 알림은 열 가지입니다 — Jira(만료 임박·만료·발신함 막힘), 미등록 계정, 서버 옛 코드, 동기화·보관함, 자동 복구, 사용량 못 받음, 신원 못 받음, GitHub 준비물, SMTP 준비물, 세션 다시 시작. 넷의 산출이 모이면 frontend-developer 가 구현하고, 열 스킨 × tone × 좁은 폭을 Chrome 과 WebKit 으로 찍어 확인한 뒤 review 카드로 올립니다. 어제의 붉은 한 줄은 그 자리로 옮겨지며 사라집니다.

### 알림 한 건의 문구 형식 (ux-writer)

한 건은 **네 칸**이다. 셋은 필수, 넷째는 선택.

```
[표식] 제목      — 무엇이. 명사구, 8자 안팎. 서비스 이름은 값 자리 {서비스}.
       본문      — 왜/언제부터. 「…습니다」 한 문장, 20자 안팎.
       행동      — 할 일(「…하기」) — 자리(화면의 글자 그대로) 또는 명령(복사).
       딸림 한 줄 — (선택) 이 행동이 끊는 것, 또는 사람 손이 필요 없다는 사실.
```

**심각도 세 등급.** 가르는 물음 한 줄: **지금 안 되고 있나 / 곧 안 되나 / 이미 끝난 일인가.**
- **막힘** — 지금 무언가가 실제로 안 되고 있고, 사람이 손대야 풀린다.
- **주의** — 아직 되지만 곧 안 된다, 또는 켜 둔 기능 하나가 안 된다.
- **정보** — 읽고 나면 할 일이 없다. 스스로 끝났거나 스스로 풀린다.

**규율 여덟.**
1. **서비스 이름은 값 자리다** — `{서비스} token 만료 임박`. Jira 를 문장에 박지 않는다. 값이 없으면 그 건은 서지 않는다.
2. **선택인 서비스는 켠 사람에게만, 막혔을 때만 선다** — 준비물이 없다는 사실 자체는 알림이 아니라 그 판의 사실 줄이다(주인 반려의 핵심). 그 서비스로 실제로 하려던 일이 막힌 뒤에 알림이 된다.
3. **세 칸이 같은 말을 되풀이하지 않는다** — 제목이 「만료됨」이면 본문은 언제·무엇이 막히는지를, 행동은 어디서 무엇을 하는지를 맡는다.
4. **심각도는 표식 칸이 말한다** — 문장 앞에 `⚠` 를 박지 않는다(지금 화면 넷이 문장 안에 박고 있다). 색만으로도 가르지 않는다(마크+글자).
5. **숫자·시간은 사람 단위** — 「0일 뒤」는 「오늘」, 「1일 뒤」는 「내일」, 그 밖만 「{N}일 뒤」. 1분 미만은 「방금」.
6. **파일 경로·내부 식별자는 문장에 쓰지 않는다**(R5) — 툴팁으로 내리고 문장에는 그것이 무엇인지를 쓴다.
7. **비난하지 않는다** — 「설정하지 않았습니다」가 아니라 「아직 없습니다」.
8. **남의 도구 이름은 원어** — token · push · pull · commit · gh · SMTP · Jira · GitHub. 이 제품이 지은 명령도 원어(`s9 sync`), 사실을 말하는 낱말은 우리 말(「동기화」).

값 자리: `{서비스}` `{계정}` `{컴퓨터}` `{N}` `{날짜}` `{시각}` `{까닭}`.

### 지금 문구에서 바뀌는 것 (before/after 요지)

1. **⚠ 가 문장에서 빠진다** — 1a·1b·1c·2·7 이 문장 앞에 `⚠` 를 박고 있다. 심각도는 표식 칸이 맡는다.
2. **「0일 뒤」→「오늘」** — 어제 반려된 그 줄의 첫째 결함이다. 남은 날을 그대로 찍으면 오늘 만료가 「0일 뒤」로 나온다(R4).
3. **Jira 가 값 자리로 내려온다** — 1a·1b·1c 가 지금은 문장에 Jira 를 박고 있다. `{서비스}` 로 두면 GitHub·SMTP 가 같은 틀에 선다. 주인 반려의 본체.
4. **선택인 서비스는 준비물만으로 서지 않는다** — 8·9 는 지금도 Settings 안에만 있다. 머리로 끌어올리지 않는다. 막혔을 때(1c 꼴)만 알림이 된다.
5. **파일 이름이 문장에서 툴팁으로 내려간다** — 3 의 `bin/s9 · bin/s9-audit-prompt` 는 R5 위반이다.
6. **「다시 떴습니다」→「다시 시작했습니다」** — 5a 의 「뜨다」는 실행을 비유로 말한 것이다(규약 2조 ②).
7. **「…한다」가 「…습니다」로** — 6 의 hovercard `아직 받지 못했다 — 60초마다 다시 물어본다.` 는 코드 주석의 어휘다(R1).
8. **행동 칸이 「…하기」로 통일된다** — 「등록하세요」·「확인하세요」 같은 명령형 문장이 빠지고, 누르는 것은 「새 token 넣기」·「명령 복사」·「다시 받기」로 결과를 말한다(R2·R3).
