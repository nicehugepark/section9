**판정.** gate 를 우리말로 부를 때는 **「검사」** 하나다 — 「문」·「관문」·「게이트」(음차)를
쓰지 않는다. 용어표 DOC-20260906-002-62x6 에 이미 그 줄이 있었는데(「문·커밋 문·게이트 → 검사」)
소스에 적용되지 않아 683곳이 남아 있었다. 코드 식별자 `concurrent_gate`·`s9-git-gate`·
`wide_gate` 는 **이 저장소가 지은 이름**이라 그대로 둔다 — 사람이 파일 이름·함수 이름·훅
이름으로 다시 만나는 글자다(규약 2조 ①, 용어표 「훅 이름은 그대로」).

읽다 보니 「문」이 gate 만 가리키는 것이 아니었다. 뜻이 넷이라 넷으로 갈라 적었다:
① 막는 장치 → **검사** (커밋 검사·스폰 검사·상태 검사) ② 모두가 지나는 한 자리 →
**경로** (같은 문 → 같은 경로, 문이 둘이면 → 경로가 둘이면) ③ 부르는 자리 → **진입점**
(들어오는 문) ④ 나가는 자리 → **나가는 경로**(화면의 누를 것이면 「손잡이」). 상태는
사실로 적었다: 「문이 선다」→「검사가 막는다」, 「문이 뽑힌다」→「사람이 검사를 꺼 버린다
(`--no-verify`)」, 「문이 열린다」→「검사가 통과시킨다」. 영문 식별자 `door`·`Door`·
`doors` 도 같은 비유라 gate·path·entry 로 바꿨다(시험 이름 20여 개).

**바꾼 자리.** `bin/`·`harness/`·`tests/` **121 파일 · 620줄**(1차 544 + 2차 76) + docs 5파일.
