규약 개정 (lead). commit 8b385a16.

바꾼 것: browser-verify 스킬 원천(harness/claude/gen_roster.py)과 PROTOCOL 19조 화면 조항.
- 실제 맥 Safari 는 **필수**다. Playwright WebKit 은 맥에 가기 전 거르기이지 대신이 아니다 — 같은 엔진 계열이라도 맥의 Safari 는 글꼴·스크롤·입력·확대에서 따로 논다.
- WebKit 캡처만 붙이고 「Safari 확인」이라 적지 않는다.
- 맥 Safari 를 못 돌렸으면 review 가 아니라 **blocked** 이고, 노트에 「맥 Safari 미실행(WebKit 만 확인)」을 그대로 적는다. 여는 조건 둘: 사람이 맥에서 확인 / 맥을 등록해 자동 실행.
스킬은 다시 생성해 설치본까지 반영됐다.

**막힌 자리**: 이 머신에서 닿는 맥이 없다. 원격 시험 머신은 확인해 보니 Linux 다(비밀 값은 읽지 않고 `s9 secret run` 으로 `uname` 만 물었다). 그래서 규칙은 섰지만 **자동 실행 경로가 없다** — 지금 상태로는 모든 화면 REQ 가 blocked 로 간다. 맥에 닿는 길을 사람이 정해 줘야 다음 단계(`s9 shot --engine safari`: ssh + safaridriver, 장치 이름은 코드 밖 state/ 에)를 만들 수 있다.
