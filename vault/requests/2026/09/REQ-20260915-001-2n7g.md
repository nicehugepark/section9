### 2026-09-15T13:28:41+09:00 tdd (agent: lead:claude-opus-5, by nicehugepark)

뿌리: `.usagechip{white-space:nowrap}` 이라 이 조각의 min-content 폭 = 글자 전체 폭(393px)이다. flex 항목의 `min-width:auto` 가 그 아래로 줄이지 못하게 막아, 머리글(400-44=356px)을 넘어 문서 전체에 가로 넘침을 만든다. 고칠 자리는 조각이 접히는 단위다 — 「5h 29%」 같은 한 덩이는 붙여 두고 덩이 사이에서만 접는다.

- [ ] 정상 — 1440px: 칩이 한 줄로 서고 `documentElement.scrollWidth == innerWidth`
- [ ] 경계 — 400px: 가로 넘침 0(`scrollWidth == innerWidth`)이고 칩의 오른끝이 창 안
- [ ] 경계 — 400px: 칩이 두 줄 이상으로 접히되 「5h 29%」·「wk 34%」·「fable 37%」는 각각 한 줄 안에 붙어 있다(덩이 안은 nowrap, 이름과 숫자가 갈리지 않는다)
- [ ] 경계 — 접힌 줄은 이름으로 시작한다: 이어짐 표시 `·` 는 앞 덩이 끝에 붙는다
- [ ] 실패 — 60자짜리 긴 메일 주소여도 400px 에서 넘치지 않는다(메일 덩이는 마지막 수단으로 아무 데서나 접힌다)
- [ ] 회귀 — soft 스킨(사이드바 셸 232px)에서도 칩이 셸 폭 안에 앉는다
- [ ] 회귀 — test_usage_chip_keeps 8항목 그대로 통과: 계정·5h·wk 글자가 남고, stale 마크(`mk mk-clock`)가 붙고, 이모지 후보 코드포인트가 없다
- [ ] 회귀 — 실브라우저(Chrome·WebKit)와 맥 실제 Safari 에서 400px 을 직접 보고 확인
