### 2026-09-08T21:02:44+09:00 response (agent: lead:claude-fable-5-1, by nicehugepark)

주인이 Settings 의 「내 GitHub 계정 쓰게 하기(auto_resume_gh)」 그림을 붙여 「이거 아닌가」 물었다(첨부 20260908T210210-image.png: Settings 항목 하나를 찍은 것).

답: 다른 스위치다. auto_resume_gh 는 **백그라운드 작업자에게 gh(GitHub CLI) 권한을 줄지**다 — 사람이 없는 사이 작업자가 내 GitHub 계정으로 명령을 칠 수 있게 하는 것(bin/s9.py 9602: 켜면 작업자 봉투에 Bash(gh:*) 가 붙는다). 문서 동기화(.s9-sync 의 remote/local — 문서 이벤트마다 commit→pull→push 할지)는 그것과 무관하고, 꺼져 있어도 문서 동기화는 git 으로 그대로 오간다. Settings 에 동기화 스위치는 없다 — 이 요청(068)이 그 자리다.
