묶음을 일관된 스냅샷에서만 짓게 했다. 조각을 쓰는 중에 온 요청은 마지막으로 내준 묶음을 그대로 받는다 — 반쯤 쓰인 조각이 실려 화면 껍데기가 안 서던 자리(events.js 의 $(s) null, 'usageLast' has already been declared)가 닫혔다.

**구현 (bin/s9.py, 묶음 자리만 · Edit 로 좁게)**
- `BUNDLE_DWELL_SEC=1.0` · `BUNDLE_WAIT_SEC=2.0` · `_BUNDLE_LAST`(마지막으로 내준 묶음) · `_BUNDLE_PART`(조각별 마지막 온전본) 를 `_BUNDLE_RESP` 옆에 세웠다.
- `web_bundle_response`: ① 껍데기+조각의 mtime 을 보고 하나라도 1초 안이면 `_BUNDLE_LAST` 를 그대로 돌려준다(같은 객체 → 같은 body·같은 ETag). 직전 묶음이 없는 첫 요청이면 조용해질 때까지 최대 2초 기다렸다 다시 본다(상한에서는 멈추고 낸다). ② 조각마다 값싼 구문 검사 — 통과한 것만 온전본으로 기억하고, 깨진 것은 직전 온전본으로 대신 싣는다(없으면 빼고 그 자리를 주석으로 말한다). ③ 캐시 키를 `(sub, 껍데기 지문, ((이름, 실제로 쓴 지문, ok|prev|skip|none), ...))` 로 바꿔 ETag 가 **실린 것**을 따르게 했다.
- `_part_syntax_error`: node 가 있으면 `node --check`, 없으면 `_balance_error`(괄호·따옴표·주석 균형 — 문자열/템플릿/정규식/주석을 건너뛴다). 이 머신에는 node 가 없어 실제로 도는 것은 균형 검사다.
- `web_bundle(sub, shell, root, parts=None)`: 검사한 자리가 읽은 조각을 그대로 넘길 수 있게 매개변수 하나를 더했다(기본값은 옛 동작 그대로).
