## Original

현재 대시보드가 실행 중인 저장소의 경로를 정확하게 표시할 필요가 있을 것 같다. 한 머신에서도 여러개의 section9이 실행될 수 있다는 사실을 알게됐네. 용도에 따라서 여러개의 section9을 실행한다면 각 대시보드가 어떤 저장소를 기준으로 실행됐는지 알 수 있어야 하고, 저장소 주소를 클릭하면 탐색기나 터미널이 해당 위치로 실행이 되던가 해야하고, stop 하는 방법도 표시 되는게 좋을 것 같다.
