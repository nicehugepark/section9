## Original

실측 2026-09-21 (주인 물음 「그럼 새로 설치할 때 git user, email을 입력받게 하는건가?」에 답하려 흐름을 되짚다가): 첫 실행은 id·성·이름 셋만 묻고 github 도 메일도 묻지 않습니다. 그래서 새로 설치한 사람은 사다리의 마지막 칸(임시값)으로 돕니다. 그 사람이 나중에 Settings 에서 github 를 적으면 그때 신원이 올라서야 하는데, 재평가(reidentify_after_profile_change)가 `s9 user add`·`s9 user attach` 두 자리에만 붙어 있습니다.

프로필을 고치는 단 하나의 자리는 do_user_update 이고 대시보드도 CLI 도 그것을 지납니다 — 거기 붙이면 모든 길이 함께 풀립니다. REQ-20260921-012-62x6 의 goal 에 「프로필 수정 뒤」가 있었는데 그 반쪽이 빠진 채 닫혔습니다.
