실물 확인 (lead).

- `/api/transitions` 실측: `open` 의 갈래가 `["blocked","cancelled","in-progress"]` — done 이 빠졌다. 나머지 상태는 그대로다(`in-progress` 는 blocked·cancelled·done·review).
- 실브라우저 캡처 `state/shots/req045-open-card.png`: open 문서(REQ-20260907-033-62x6)의 손잡이 줄이 「담당 바꾸기 · → blocked · → cancelled · → in-progress · 이어 말하기」이고 **「완료」는 없다.**
- 화면 쪽에 따로 굳어 있는 목록은 없었다 — `web/app/boot.js` 가 `/api/transitions` 응답을 그대로 버튼으로 만들므로 서버 한 곳만 고쳐도 된다는 architect 의 판단이 맞았다. web/ 은 손대지 않았다.
