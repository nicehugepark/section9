```
git show HEAD:web/css/docs.css | grep -c "tr.day"   → 0
grep -c "tr.day" web/css/docs.css                    → 3
```

원격 CI 클론(`/home/sjpark/section9-ci/section9`)은 HEAD 를 받으므로 시험은 있고 CSS 는 없다. REQ-20260910-025-62x6(Audit 날짜 열)를 닫을 때 화면은 눈으로 확인했지만 **그 CSS 가 담겼는지는 확인하지 않았다** — 내 잘못이다.

**규율로 남길 것**: 화면 요청을 닫기 전에 `git show HEAD:<그 파일>` 로 **담겼는지**를 본다. 「화면에서 보인다」와 「담겼다」는 다른 사실이다 — 작업 트리에서만 보이는 것은 다른 컴퓨터에서는 없는 것이고, 원격 전체 테스트가 그것을 잡는다.
