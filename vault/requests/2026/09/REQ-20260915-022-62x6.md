## Original

REQ-20260915-021 을 고치다 남은 갈래. `s9 commit` 은 ROOT(본 저장소) 기준으로 담을 것을 세므로 요청 전용 worktree 안에서 부르면 담을 것이 없다고 답한다. 그래서 worktree 작업자는 plain git commit 을 쓸 수밖에 없고, 공유 index 를 피해 담는 길(임시 index·sync 잠금)을 쓰지 못한다.
