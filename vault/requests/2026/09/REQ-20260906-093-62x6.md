### WebKit 경로 실측 (2026-09-06 20:42~20:50)

Safari 는 어디에도 없다 — WSL·Windows·원격 테스트 머신(Linux, Ubuntu 25.10) 모두. 시도한 경로:
1. 원격 머신에 Playwright WebKit: 설치는 되나 실행에 root 권한의 시스템 라이브러리(libavif16·libmanette 등)가 필요하고 sudo 가 없다. apt 도 25.10 을 지원하지 않는다(libicu74 없음). docker 는 있으나 그룹 권한 없음. → 불가.
2. **Windows 쪽 Playwright WebKit(채택)**: 관리자 권한 없이 된다. 이동식 node(v22.23.2 zip)를 `C:\Temp\s9-webkit` 에 풀고 `npx playwright install webkit` — 엔진 webkit-2359 가 `%LOCALAPPDATA%\ms-playwright` 에 놓인다. 찍기는 `run-npx.cmd screenshot --browser=webkit --viewport-size=W,H --wait-for-timeout=4000 <url> <png>`.
