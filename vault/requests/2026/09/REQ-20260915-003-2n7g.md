## Original

전체 테스트 실행(2026-09-15 13:49, 맥, 3722항목 중 1실패):

FAIL: test_no_third_party_imports (test_stdlib_only.TestStdlibOnly)
AssertionError: ['bin/s9_firstrun.py: import winreg'] is not false

뿌리는 tests/test_stdlib_only.py 의 stdlib_names() 폴백이다. python 3.10+ 에서는
sys.stdlib_module_names 가 플랫폼과 무관하게 winreg 를 포함하지만, 맥의 기본
python3 는 3.9 라 그 속성이 없어 파일 시스템(stdlib 디렉터리·lib-dynload)에서
목록을 만든다 — 맥에는 winreg 파일이 없으니 목록에 없고, 윈도우 전용 표준
모듈을 전부 서드파티로 본다.

import winreg 는 REQ-20260915-006-62x6(b8b8fb394)이 들여온 것이고 그 자체는
옳다(윈도우에서만 부른다). 고칠 자리는 시험의 폴백 목록이다 — 윈도우 전용
표준 모듈 이름을 폴백에 더하거나, 3.9 에서는 플랫폼 밖 모듈을 판정 대상에서
뺀다.

이 실패는 REQ-20260915-001-2n7g 의 변경(web/css·web/app·tests)과 무관하다 —
bin/ 은 손대지 않았다.
