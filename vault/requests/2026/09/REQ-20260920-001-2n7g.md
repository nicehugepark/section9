구현: bin/s9-doctor 에 ident_info(수집) · ident_verdict(판정) 를 더하고 system_checks() 에 세웠습니다. 수집기는 사람이 정해 둔 값(`git config --get user.name·user.email`)과 실제로 찍힐 값(`git var GIT_AUTHOR_IDENT`) 을 함께 읽습니다 — 둘을 같이 읽어야 「정해 두지 않았다」와 「그래서 지금 무엇으로 찍히고 있나」를 한 줄에 적을 수 있습니다.

판정은 넷입니다. ① git 이 누구로 commit 할지 전혀 못 정하면 critical(commit 이 거부됩니다) ② 이름·메일을 정해 두지 않았으면 warn ③ 정해 뒀어도 메일이 이 컴퓨터 안에서만 닿는 주소(.local · .localdomain · .lan · .home · (none))면 warn ④ 나머지는 ok. 셋 다 조치에 `git config --global` 두 줄과 「이미 쌓인 commit 은 그대로다」를 함께 적습니다.
