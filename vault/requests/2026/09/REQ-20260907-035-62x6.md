### 2026-09-07T14:37:22+09:00 response (agent: lead:claude-opus-5, by nicehugepark)

구현 (lead, size S 예산 안).

- `browser_open_cmd(url)` — 판별과 실행을 갈랐다. argv 만 돌려주므로 시험이 브라우저를 띄우지 않는다. macOS `open` · Windows `cmd /c start` · WSL `wslview` → `explorer.exe` → `cmd.exe /c start` · Linux `xdg-open` → `gio open`. 후보가 없으면 None.
- WSL 에서 xdg-open 을 먼저 보지 않는 이유: 리눅스 안에서 열려 사람 눈에 안 보인다.
- `browser_open(url)` — 최선 노력. explorer.exe 는 성공해도 1 로 끝나므로 종료 코드로 판정하지 않고 Popen 만 한다. 실패해도 s9 code 는 그대로 간다.
- `cmd_code`: 갓 띄운 서버는 아직 답하지 않으므로 왕복이 될 때까지 최대 10초 기다린 뒤 연다 — 「연결할 수 없음」 화면을 사람이 고장으로 읽지 않게.
- 끄는 길 둘: `s9 code --no-open` · `S9_NO_OPEN=1`. `--no-open` 은 claude 로 넘기지 않는다(`_own` 목록).
- 시험 tests/test_code_open.py 7건 통과(0.005초). 이 판 실측: plat=WSL, 고른 명령 explorer.exe, `s9 code --no-claude` 로 브라우저가 실제로 열렸다.
