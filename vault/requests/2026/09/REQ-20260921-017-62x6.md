## Original

실측 2026-09-21 (REQ-20260921-011-62x6 을 닫으며): pick_identity 를 샌드박스에서 직접 불러 보니 프로필에 first_name·last_name 이 있어도 이름 칸이 언제나 id 로 섭니다. architect 의 설계는 「emails[0] + first_name/last_name(없으면 id)」였습니다.

다만 id 가 더 나을 수도 있습니다 — GitHub 의 commit 작성자 이름은 로마자가 관례이고, 한글 이름이 박히면 목록에서 어색합니다. ux-writer 는 「commit 에 적을 이름은 기본으로 사람 이름을 쓰되, 로마자로 적고 싶으면 거기서 바꾸게」를 냈습니다.

이 요청은 그 둘 중 무엇이 기본값인지를 정하는 자리입니다. 화면에 보이는 이름과 commit 에 박히는 이름이 갈려도 되는가가 가르는 물음입니다.
