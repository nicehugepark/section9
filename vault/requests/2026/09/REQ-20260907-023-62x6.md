### 스킨 간 어휘 통일 — 고친 것

잣대는 개정안 ①이다: **스킨은 재질(색·면·깊이·모서리)을 바꾸고 어휘와 자리는 바꾸지 않는다.** soft 가 어긴 것이 둘이었고, 둘 다 override 를 걷어 base 로 돌려보내는 것으로 끝났다 — 새 규칙을 더하지 않았다.

**① 사람 이름의 색면 칩** (web/css/skins.css)
```
[data-skin="soft"] .badge{background:var(--accent-soft);border-radius:5px;padding:1px 7px}
[data-skin="soft"] .badge::before{content:""}
```
칠한 칩이라 이 화면이 금한 색면 하이라이트이고, `::before` 를 지워 `@` 접두까지 없앴다 — 같은 사실이 스킨마다 다른 부품으로 읽혔다. 두 줄을 걷으니 soft 도 base 의 `@이름`(점선 밑줄이 「눌러서 담당을 바꾼다」를 말한다)으로 돌아온다.

**② 판 폭을 먹는 「더 보기」 상자** (web/css/skins.css)
```
[data-skin="soft"] .more{border:1px dashed var(--border);border-radius:8px;text-align:center}
[data-skin="soft"] .more::before{content:""}
```
점선 테두리 상자 + 가운데 정렬 + `+ ` 접두 제거였다. 걷으니 다른 스킨과 같은 글자 버튼(`+ N개 더 보기`, hover 밑줄)이 된다. soft 의 둥근 재질은 카드·판이 이미 말하고 있어 잃는 것이 없다.

### 손대지 않은 것과 까닭
- **calm 의 이니셜 링(.av)** — `@` 대신 원 안의 머리글자를 세운다. 어휘가 갈린 것처럼 보이지만 이것은 REQ-20260902-021-62x6 에서 사용자 판정으로 확정된 calm 전용 마크이고, 자리(이름 앞)와 뜻(담당)이 같다. 되돌리는 것은 이 요청의 크기(S) 밖이라 그대로 두었다 — 되돌릴 뜻이면 별도 요청으로 세워야 한다.
- **calm·glass 의 `.more` hover 배경** — 쉼 얼굴은 base 와 같은 글자 버튼이고 hover 의 옅은 틴트만 다르다. 재질이라 규칙 안이다.
- **soft 의 `.kind` 색면 칩(Docs 타입 표기)** — 같은 병이지만 Docs 화면이라 이 요청(카드)의 범위 밖이다. 별도 요청감으로 남긴다.
