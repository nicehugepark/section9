### 스킨 계약을 시험으로 잠갔다 — 새 어긋남은 막고, 있던 둘은 얼렸다

**한 일**: `tests/test_skin_contract.py` (5건) 을 세웠다. s9-design 규칙 1(스킨은
재질을 바꾸고 어휘와 자리는 바꾸지 않는다, REQ-20260907-011-62x6)이 2026-09-07 이후
말로만 있었고, 기계가 세지 않으니 calm 이 카드를 `order` 로 다시 세우고 이름 앞
`@` 를 지운 뒤 이니셜 원을 대신 세웠다 (REQ-20260910-009-62x6 designer 전수 점검 ③).

**재는 자리는 카드 안이다.** 규칙 1 의 예(사람 이름·경과·더 보기)가 전부 카드의
조각이고, `soft` 는 「구조부터 다른 언어」로 세운 사이드바 셸(skins.css:2)이라
머리를 통째로 다시 세운다 — 판 껍데기까지 재면 규칙 1 이 아니라 스킨이라는 축
자체를 부정하게 된다. 그래서 선택자에 `.card` 가 있는 스킨 규칙만 본다.

**막는 것 넷**: ① 카드 조각의 `order` ② 카드 안 `::before/::after` 의 `content`
③ base 가 `display:none` 으로 숨긴 부품을 한 스킨만 켜는 것 ④ 카드 조각을 흐름
밖으로 빼는 것(position·float). 넷을 한꺼번에 넣은 임시 CSS 로 각각 잡히는 것을
확인했다.

**있던 어긋남은 LEGACY 목록에 선택자 한 줄씩 얼렸다** — calm 의 카드 재배치 6줄과
`.badge::before{content:none}`·`.av{display:...}` 둘. 다섯째 시험이 「목록의 줄이
CSS 에 없으면 목록에서도 지우라」고 말하므로 목록은 **줄기만 한다**. 얼린 이유는
푸는 방향이 둘이고 그 선택이 취향이기 때문이다: calm 을 base 로 되돌리거나
(REQ-20260907-023-62x6 이 soft 에 한 방식), 제목 먼저를 전 스킨의 기본으로 올리거나.
어느 쪽이든 화면이 바뀌므로 사람의 몫으로 남겼다.

**덤으로 걷은 한 줄**: `[data-skin="calm"] .card .tag::before{content:none}` —
base 에 `.tag::before` 가 없어 하는 일이 없던 규칙이다. 태그의 `#` 는 card.js 가
글자로 찍는다(`card.js:2130`), 캡처로 확인했다.

**S3 원안과 달라진 것**: designer 가 제안한 시험 3건 중 둘째(「`.card .id` 가 한
줄」)는 세우지 않았다. 같은 진단이 P3 로 이미 철회됐다 — 줄 수를 정하는 것은
스킨이 아니라 카드 안쪽 폭(`@container (max-width:200px)`)이고, 잠그니 식별자가
0폭으로 눌려 사라졌다(REQ-20260910-009-62x6 designer 실측). 그 자리는 「흐름 밖으로
빼지 않는다」로 대신했다.

**검증**: 새 시험 5건 + 관련 26건 통과(test_calm_density·test_card_corner·
test_control_scale·test_css_section·test_rail_head_rule). calm Board 실브라우저
캡처 1장(첨부). 전체 테스트는 리드의 commit 뒤 백그라운드가 돌린다(규약 18조).

**예산**: size S 15분에 접수→작업 22분. 초과 사유는 S3 원안 3건을 그대로 세울지
판정하려고 부모 요청의 P3 철회 경위를 읽은 것이다 — 읽지 않았으면 이미 틀린
것으로 판명된 시험을 세울 뻔했다.
