### 고친 자리 — 시험 쪽이다, CSS 는 한 글자도 안 바꿨다 (commit e8947501c)

두 계약이 부딪힌 것이라 요청의 판정대로 **S3 의 뜻을 좁혔다**: 스크롤바 선택자의 블록이
**지우는 선언만**(`display:none` · `width/height:0`) 담고 있으면 아무것도 그리지 않으므로
스킨마다 다른 그림이 새어 나올 수 없다 — 세지 않는다. 색·폭·모양을 다시 정하는 선언이
하나라도 섞이면 그대로 잡는다.

- `tests/test_scrollbar.py` — 판정을 모듈 함수 `invents_its_own(css)` 로 떼어냈다(주석은
  `/*…*/` 를 걷고 읽는다). S3 이 그것을 쓰고, 새 시나리오 `test_s3_hiding_is_not_inventing`
  이 가짜 CSS 넷으로 경계·실패를 직접 잰다 — 실제 파일에 기대지 않으므로 다음에
  tablet.css 가 바뀌어도 이 판정 자체는 계속 검증된다. 머리말의 S3 조항에 까닭을 적었다.
