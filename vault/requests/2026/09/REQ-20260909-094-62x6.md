### ① 문구

`web/app/refs.js` `.dslegend`: 「막힌 요청 ↳ **기다리는** 선행 작업」 → 「막힌 요청 ↳ **끝나야 할** 선행 작업」 (ux-writer 판정, 같은 문서의 subagent 노트). 「기다리는」이 바로 뒤의 「선행 작업」을 수식해 **선행 쪽이 기다리는 중**으로 읽히던 것이 뒤집힌 뜻이었다 — 실제로는 윗줄(막힌 요청)이 기다리고 아랫줄이 끝나야 하는 쪽이다. 레일 제목·개수·빈 상태 문구는 이미 「막힌」·「선행」과 어긋나지 않아 그대로 뒀다. 폭 318px 한 줄(20px)로 접히지 않는다 — 첨부 캡처(Chrome, 배율 2, Graph 탭 오른쪽 레일).

### ② 새 탭 — 전수 목록

규칙 하나(`web/app/events.js` `navHashFor`)가 두 갈래를 가른다. **앵커는 브라우저 몫**(우리가 열면 탭이 둘 열린다), **div/button 손잡이는 우리가 연다**. 주소는 화면을 여는 손(`docOpen`·`pushRoute`)과 같은 규칙으로 짓는다.

앵커라 이미 되던 것(손대지 않음): 문서 링크 `a.doclink`(state.js `dlink` 한 곳에서 만든다) · 터미널 문서 언급 `a.doclink[data-tdoc]`(ccrender.js) · Jira 키 `a.jkey`(card.js·docs.js) · Settings 「가이드 열기」(settings.js) · 프로젝트 문맥 띠 「열기」 `a.pjs-open` · 「사용자 관리로」 `a[href="#settings/users"]`.

새로 받는 것(`navHashFor` + auxclick + Ctrl/⌘/Shift 클릭):
- Board 카드 `div.card[data-doc]` → `#docs/<id>` (카드는 draggable div 라 앵커로 못 바꾼다)
- Docs 목록 행 `div.row[data-doc]` → `#docs/<id>`
- Linked mentions `div.bl[data-doc]` → `#docs/<id>`
- Projects 레일 행 `div.row.pjrow[data-doc]` → `#projects/<id>`
- Stream 탭 세션 줄 `[data-stream]` → `#stream/<sid>`
- Settings 항목 `[data-sset]` → `#settings/<구역>`
- 터미널 미리보기의 「문서 열기」 `button[data-popen]` → 그 문서
- 카드의 「선행 대기 현황 →」 `button[data-goto]`(탭 이름일 때만 — 값에 `|` 가 있으면 상태 전이라 주소가 아니다)

**손잡이 안의 손잡이는 열지 않는다**: 카드 안의 「이어 말하기」·승인/반려·벨트 글리프·Jira 키처럼 안쪽에 제 일을 가진 button/앵커가 있으면 그것이 이긴다 — 주소가 아니라 행동이다.

**곁가지 하나**: `dlink` 가 `#docs/<id>` 를 박아 두어 프로젝트 문서 링크는 왼쪽 클릭만 Projects 탭으로 갔고 새 탭·북마크는 Docs 탭을 열었다. 판정을 `docTab`/`docHash`(state.js) 한 곳으로 모으고 `docOpen` 도 그것을 부른다.
