### 2026-09-13T17:42:05+09:00 response (agent: lead:claude-opus-5, by nicehugepark)

맥 tar.gz 실측 절차 — 이어받는 사람이 그대로 치면 되는 것

R2 가 서기 전이라도 git archive 로 배포판을 흉내 내 잴 수 있다. 이 맥의 실제
설치를 건드리지 않으려면 HOME 을 갈아 끼우는 3단계를 반드시 지켜야 한다.

1. 배포판을 만든다 (저장소에서)
   cd ~/section9
   git archive --format=tar.gz --prefix=section9/ -o /tmp/section9-0.9.0-mac.tar.gz HEAD bin web harness docs README.md CLAUDE.md pyproject.toml

2. 깨끗한 자리에 푼다
   mkdir -p /tmp/s9first && cd /tmp/s9first
   tar xzf /tmp/section9-0.9.0-mac.tar.gz
   cd /tmp/s9first/section9

3. HOME 을 갈아 끼우고 첫 실행 (claude 는 띄우지 않는다)
   env HOME=/tmp/s9first/home S9_NO_OPEN=1 bin/s9 code --no-claude

무엇을 볼 것인가
- 「section9 훅 미설치 감지」가 뜨고 s9-install 이 스스로 도는가
- 「git repo 아님 — git hooks 생략」이 뜨는가 (뜨면 R3 의 구멍이 실측으로 확인된 것)
- 대시보드가 뜨고 http 로 답하는가 (포트는 9909 가 차 있으면 +1)
- env HOME=/tmp/s9first/home bin/s9 ls 가 오류 없이 끝나는가
- env HOME=/tmp/s9first/home bin/s9 doctor --live 가 맥에서 세션 판정을 하는가

절대 하지 말 것
- HOME= 을 빼고 실행하지 마라. 이 맥의 ~/.claude/settings.json 의 훅이 /tmp 사본을
  가리키도록 다시 쓰여, 진짜 세션의 audit 이 조용히 죽는다. 그렇게 됐으면 복구는
  cd ~/section9 && bin/s9-install 이다.
- 저장소 안(scratchpad/ 포함)에 풀지 마라. git 이 상위로 올라가 본 저장소를 찾아,
  사본의 sync 가 본 저장소에 commit 할 수 있다.

끝낸 뒤
- 띄운 대시보드는 pid 로 종료한다(pkill 은 제 셸을 먼저 잡는다).
- rm -rf /tmp/s9first /tmp/section9-0.9.0-mac.tar.gz
