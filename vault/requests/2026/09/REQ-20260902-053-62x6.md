### ① DNS 터널링 (먼저 이것부터)

1. Windows 탐색기 주소창에 `%UserProfile%` 을 치고 그 폴더를 연다.
2. `.wslconfig` 파일을 연다(없으면 새로 만든다 — 확장자 없는 그 이름 그대로).
3. 아래를 적고 저장한다. 이미 `[wsl2]` 절이 있으면 그 아래에 줄만 더한다.

   ```
   [wsl2]
   dnsTunneling=true
   autoProxy=true
   ```

4. Windows PowerShell 에서 `wsl --shutdown` 을 친다. 30초 기다렸다가 WSL 을
   다시 연다.
5. 확인: `~/section9/bin/s9 metrics status` 가 「돌고 있다」면 계기가 다시 섰다.

### ② 그래도 나면 — 미러 네트워킹 (Windows 11 22H2 이상만)

같은 `.wslconfig` 의 `[wsl2]` 절에 `networkingMode=mirrored` 를 더하고
4~5 를 되풀이한다. 이 모드는 WSL 이 Windows 의 랜카드를 그대로 쓴다 —
NAT 계층이 통째로 빠지므로 그 계층에서 나던 끊김이면 사라진다.

**하지 말 것**: 두 설정을 한꺼번에 켜지 마라. `resolv.conf` 를 손으로 고치지
마라(재시작마다 덮어써진다 — 고치려면 `/etc/wsl.conf` 의
`generateResolvConf=false` 가 함께 필요하고, 그건 ①·②가 다 실패한 뒤의 셋째
수단이다).
