맞는 지적입니다 — **타치코마가 designer 의 권고를 제 손으로 CSS 에 붙였고, 그것이 규약 7조 위반이었습니다.** 결과가 지금 화면입니다: 「⟳ 자동 복구 7회」 옆에 같은 얼굴로 선 「휴지통 127」은 갈 곳이 아니라 **계기판 숫자**로 읽힙니다. 툴바 행에서 폭이 안 맞아 브랜드 행으로 옮긴 것도 설계가 아니라 자리가 남는 데로 도망간 것이었습니다.

**designer 에게 설계와 구현을 통째로 넘겼습니다 — 지금 돌고 있습니다.** 이번에는 판정만이 아니라 web/ 의 HTML·CSS·JS 를 직접 고치게 했고, 타치코마는 CSS 를 만지지 않습니다.

designer 에게 답하라고 한 것:
- 이 제품에서 「갈 곳」의 문법은 **탭 줄**입니다 — 휴지통이 거기 어떤 꼴로 서야 하는가. 상태 칩과는 다른 얼굴이어야 합니다.
- 수(127)가 필요한가, 필요하면 굵은 수 말고 어떤 얼굴인가 — 지금 그 문법이 거르개 칩과 같아서 눈이 거르개로 분류합니다.
- Docs 목록 머리의 손잡이와 Settings 맨 아래 「시스템」에 묻힌 한 줄은 어떻게 하나.
- 768px 태블릿에서도 같은 답이 서는가.
- **Board 탭에서 눌렀을 때** 판이 어디에 어떻게 서는지 — 실제로 눌러 보고 답할 것.
