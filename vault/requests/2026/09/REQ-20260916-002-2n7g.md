## Original

실제 발생 2026-09-15 23:55, commit 410cb0fa1 (REQ-20260915-014-2n7g):

`start_dashboard()` 가 `own = main_worktree_root(...)` 를 맨 앞에서 부르는데, 그 값은
바로 다음 줄의 `if not told and ...` 에서만 쓰인다. 포트를 들었으면(told) 쓰이지 않는
답이다.

그 호출이 `subprocess.run(["git", ...])` 이라, `subprocess.Popen` 을 닫아 둔
`test_port_pin_ghost.test_a2` 에서 터진다 —
`TypeError: NoneType object does not support the context manager protocol`.
그 시험은 포트를 `1` 로 적어 두고(told) 설치가 serve 를 `--port-auto` 로 세우는지만
잰다. 닫아 둔 것은 기동이지 git 이 아니다.

쓸 때 묻게 옮긴다 — 시험을 느슨하게 하지 않고, 설치도 필요 없는 git 호출을 하지 않는다.

이 실패가 지금 저장소 전체의 커밋 차단에 얹혀 있다.
