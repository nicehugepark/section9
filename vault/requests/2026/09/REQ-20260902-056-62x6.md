## Original

054 의 수집기는 세션 시작 훅이 세운다. 그래서 기계가 재시작되면 첫 Claude 세션이 열릴 때까지 표본이 없다 — 정작 부팅 직후의 불안정한 구간이 빈다.

메우는 길은 바깥 스케줄러 없이도 하나 있다: /etc/wsl.conf 의 [boot] command.
다만 root 권한과 `wsl --shutdown` 이 필요해 리드가 대신 할 수 없다.

사람이 밟을 절차 (Windows PowerShell 과 WSL 셸 양쪽):
1. WSL 셸에서: `sudo tee -a /etc/wsl.conf` 로 아래 두 줄을 더한다
     [boot]
     command = su - sjpark1 -c "/home/sjpark1/section9/bin/s9 metrics start"
2. Windows PowerShell 에서: `wsl --shutdown`
3. WSL 을 다시 열고: `~/section9/bin/s9 metrics status` — 세션을 열기 전에
   이미 "돌고 있다" 로 나오면 성공이다.

하지 말 것: systemd/cron 으로 돌리는 것 (이 저장소가 배제한 길이다).

### 리드가 밟을 수 있는 데까지 밟았다 — 남은 한 걸음은 root 다

실측: `sudo -n true` → "a password is required". 이 세션은 대화형 암호 입력이
없으니 /etc/wsl.conf 를 못 고친다. 그래서 blocked 로 세운다.

**요청서의 절차를 한 군데 고쳐야 한다.** 이 기계의 /etc/wsl.conf 에는 이미
`[boot]` 절이 있다:

    [boot]
    systemd=true

여기에 `tee -a` 로 `[boot]` 를 한 번 더 붙이면 절이 둘이 되어 뒤엣것이
무시될 수 있다. **줄만** 더해야 한다.

#### 1단계 — WSL 셸에서 (디렉토리 무관)

    sudo sed -i '/^\[boot\]/a command = su - sjpark1 -c "/home/sjpark1/section9/bin/s9 metrics start"' /etc/wsl.conf

확인:

    cat /etc/wsl.conf

이렇게 세 줄이면 맞다:

    [boot]
    command = su - sjpark1 -c "/home/sjpark1/section9/bin/s9 metrics start"
    systemd=true

#### 2단계 — Windows PowerShell 에서

    wsl --shutdown

#### 3단계 — WSL 을 다시 열고, **Claude 세션을 시작하기 전에**

    ~/section9/bin/s9 metrics status

"수집기: 돌고 있다 (pid …)" 로 나오면 성공이다. "멈춰 있다" 면 실패이니
`cat /home/sjpark1/section9/state/metrics/collector.err` 를 보여 달라.

#### 하지 말 것

- systemd 유닛·cron 으로 돌리는 것 (이 저장소가 배제한 길이다)
- `[boot]` 절을 새로 덧붙이는 것 (위 1단계가 그것을 피한다)

**곁가지 하나**: 이 절차가 세우는 수집기는 REQ-20260902-062-62x6 의 관문을 지난다 —
실저장소 자리에서 뜨므로 임시 사본 판정에 걸리지 않는다.

### 취소 — 요구 자체가 이 하네스의 규율에 걸린다

사용자 지적(대시보드 채팅 2026-09-03 10:53): "하네스 시스템이 os 시스템에 종속적인걸 원치 않는데, os 입장에서는 언제든지 사라질 수 있는데 애플리케이션이다. … 이런식으로 해결하는거라면 그냥 취소되는게 맞다."

옳다. 이 요청이 메우려던 공백은 **`/etc/wsl.conf` 의 `[boot] command`** 로만 메워지는데, 그것은 OS 안쪽에 자리를 얻는 일이다 — 저장소를 지워도 그 설정이 남는다. 하네스는 응용 프로그램이고, OS 는 언제든 이것을 죽일 수 있으며 **그래도 되어야 한다.** 죽지 않게 만들려고 OS 를 고치는 방향은 뿌리부터 틀렸다.

**그래서 남는 답은 이미 서 있다.** 계기는 부팅 시각이 바뀌면 표본 앞에 표식을 세운다 — 「기계가 다시 떴다 — 앞의 공백은 수집 중단이다」. 공백을 없애는 대신 **공백이라고 적는 것**이 이 판의 정답이다. 0 으로 채우면 사람이 「그때 한가했다」로 읽는다.

부팅 직후 구간이 정말 필요해지면 그때 답은 OS 가 아니라 **더 이른 자리에서 스스로 서는 것**(세션 훅보다 앞선 우리 쪽 진입점)이지, 부팅 스크립트가 아니다.

규율을 문서로 세웠다 — 「하네스는 OS 에 기대지 않는다」. 가르는 물음 한 줄: **이 저장소를 지우면 그 설정도 함께 사라지는가.** 안 사라지면 금지다.
