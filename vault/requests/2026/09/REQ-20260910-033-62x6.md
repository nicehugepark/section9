## Original

실측 2026-09-10 11:13: 캡처 파일 `j1-쉼-calm-판전체.png` 등을 붙인 뒤 sync 가 「commit 실패: error: pathspec ... 로 다섯 번 연속 실패했다. 동기화가 멎어 다른 컴퓨터로 일을 보낼 수 없었다. 손으로 `git config core.quotepath false` 를 주니 곧바로 통과했다.

고칠 자리 둘. ① sync 의 commit 이 경로를 git 에 넘기는 자리 — quotepath 설정에 기대지 말고 `-z`·`--pathspec-from-file` 같은 안전한 길로. ② `bin/s9-install` 이 이 저장소의 git 설정을 손보는 자리에 `core.quotepath=false` 를 함께 둔다(설정 하나로 막을 수 있는 것을 사람이 겪게 하지 않는다).

지금 이 컴퓨터에는 손으로 설정해 두었으니 여기서는 재현되지 않는다 — 재현하려면 `git config core.quotepath true` 로 되돌리고 한글 이름 파일을 하나 붙여 sync 를 부르면 된다.
