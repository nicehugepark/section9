### 리드가 먼저 못박는 제약 (설계·구현이 이 위에서 움직인다)

「손으로 받고 올린다」는 화면 문제이기 전에 **안전 문제**다. 이 저장소에는
사람이 안 보는 자리에서 도는 작업자가 있고, 작업 트리가 늘 깨끗하지도 않다.
아래는 협상 대상이 아니다.

1. **화면이 커밋하지 않는다.** 올리는 것은 **이미 커밋된 것**뿐이다. 화면이
   `add`·`commit` 을 대신하면, 누구도 무엇을 올렸는지 모르는 커밋이 생긴다 —
   이 저장소가 이미 겪은 사고 계열이다(남의 미커밋 편집을 삼킴).
2. **도는 작업자가 있으면 올리지 않는다.** 거부하고 **왜**를 말한다. 지금
   무엇이 도는지는 서버가 이미 안다(대시보드가 「도는 일 N건」을 그린다).
3. **받기(pull)는 작업 트리가 깨끗할 때만.** 더러우면 거부하고 무엇이 걸리는지
   파일 이름으로 말한다. 치워 두었다 되돌리는 명령을 화면이 대신 쓰지 마라 —
   그것이 이 저장소가 남의 작업을 잃은 그 명령이고, bin/s9-git-gate 가 막는
   이유다.
4. **갈라진 역사는 화면이 합치지 않는다.** 앞선 것과 뒤진 것이 둘 다 0이
   아니면 거부하고 사람에게 넘긴다. 화면이 merge/rebase 를 고르면 안 된다.
5. **올리기는 바깥으로 나가는 일이다** — 확인 창을 지난다. 받기는 되돌릴 수
   있으니 확인 없이.
6. **누르기 전에 상태가 보인다.** 원격과 얼마나 벌어졌는지(앞선 것 N · 뒤진 것
   N), 작업 트리가 깨끗한지가 단추 옆에 이미 서 있어야 한다 — 눌러 봐야
   아는 화면은 만들지 않는다.
7. 권한: 본인 계정의 일이 아니라 **이 저장소의 일**이다. 누가 눌러도 되는지를
   설계가 답해야 한다(admin 만인가, 등록 사용자 전부인가).

  30초마다 물으면 하루 2,880번 원격을 두드린다. 저장소 거리는 Board 의 「지금 무엇이
  도는가」와 달리 **올리려고 마음먹었을 때** 알면 되는 값이다.
- 값싼 쪽만 10초로 돌리는 것은 live follow 규율(화면 가시 + 요소 존재 + 탭 이탈 시 정리)을
  그대로 따른다 — 다른 창에서 커밋하면 이 화면이 조용히 낡기 때문이다.
- **나이를 숨기지 않는다.** 「받을 것」 숫자 아래 늘 한 줄: `원격에는 5분 전에 물어봤습니다`
  / 60초 안이면 `방금 원격에 물어봤습니다` / 한 번도 안 물어봤으면
  `원격에는 아직 물어보지 않았습니다`. **「지금 확인」은 아무것도 바꾸지 않는 손잡이**라
  확인 창이 없다.
- 대안 (B) 열 때마다 무조건 원격에 묻기: **기각** — 설정을 보러 잠깐 들른 사람에게 매번
  몇 초를 물린다. (C) 물어본 적 없음을 0 으로 그리기: **기각** — 화면이 모르는 것을
  「없다」로 말하는 것은 이 저장소가 이미 한 번 반려한 거짓말이다(REQ-20260901-013-62x6).

### 3. 손잡이 둘 — 한 줄이 아니라 두 행, 나란히 서되 받기가 먼저

**둘은 각각 `.metatbl.wtbl` 한 행이다** — 상태 표와 같은 부품, 첫 칸에 이름과 **실제로
돌아가는 명령**(mono).

    ┌───────────────────┬──────────────────────────────────────────────┐
    │ 받기               │ [ 커밋 2개 받기 ]                            │
    │ (앞으로만 붙이는    │ 원격에 새로 올라온 것을 이 저장소로 가져옵니다. │
    │  방식 · mono)      │                                              │
    ├───────────────────┼──────────────────────────────────────────────┤
    │ 올리기             │ [ 커밋 3개 올리기 ]                          │
    │ (mono)             │ 이미 커밋한 것을 GitHub 으로 내보냅니다.       │
    └───────────────────┴──────────────────────────────────────────────┘

첫 칸의 mono 줄에 **화면이 실제로 돌리는 명령을 그대로 적는다.** 022 의 근거
(터미널에서 그 글자를 치던 사람이 화면에서 눈으로 찾을 수 있어야 한다)가 여기서는 한 겹
더 세다 — 그 줄이 곧 **안전 고지**다: 숨은 강제 옵션도, 치워 두었다 되돌리는 명령도,
역사를 합치는 선택도 거기 없다는 것을 사람이 눈으로 확인한다. 앞으로만 붙이는 방식으로
받는다는 것이 글자에 박혀 있어, 리드 제약 4(갈라진 역사는 화면이 합치지 않는다)가
문장이 아니라 **기계로** 지켜짐을 보여 준다.

**되돌릴 수 있는 것과 바깥으로 나가는 것의 무게 차이 — 색면 없이 셋으로**

1. **낱말과 숫자**: 라벨이 무엇이 몇 개 움직이는지 말한다(`커밋 3개 올리기`). 뜻 줄의
   동사가 방향을 말한다 — 받기는 「가져옵니다」, 올리기는 「내보냅니다」.
2. **마찰**: 올리기만 확인 창을 지난다(5절). 받기는 없다 — 되돌릴 수 있는 쪽에 마찰을
   물리지 않는다(022 의 gh 스위치가 세운 그 규칙: 켤 때만 창, 끌 때는 없다).
3. **순서**: 받기가 위, 올리기가 아래. **읽는 순서가 곧 안전한 순서**다(받고 나서 올린다).

**판 위에서 두 단추는 같은 옷을 입는다** — `.acts button.deed`(본문체 600, 1px 보더,
hover 반전). 대안 (B) 「올리기만 잉크 채움(`.dlgyes` 처럼)」은 **기각**이다: (a) 상시
반전은 이 화면에서 hover 의 얼굴이라 늘 손이 얹힌 것처럼 읽히고, (b) 상시 강조는 사흘이면
벽지가 되며, (c) **무엇이 주 행동인지는 상태가 정한다** — 받을 것이 있으면 받기가 주
행동이고 올릴 것만 있으면 올리기가 주 행동이다. 칠로 못박은 위계는 절반의 경우 틀린다.
이 판에서 **주 강조는 「지금 잠기지 않은 단추」 하나**이고, 잉크 채움은 확인 창 안에서만
쓴다(`.dlgyes` 는 이미 그 옷이다).

대안 (C) 둘을 멀리 갈라 두 덩이로: **기각** — 둘은 한 축의 두 방향이라 갈라 두면
「먼저 받고 올린다」는 순서가 안 읽힌다. 다만 ▶/⏸ 같은 **화살표 글리프는 쓰지 않는다** —
재생기 글리프는 「한 축의 두 방향, 하나만 참」을 약속하는데 받기와 올리기는 동시에 참일
수 있다(REQ-20260830-042-62x6 의 배타 규칙). **글리프 없는 낱말 단추 둘.** 부수 이득: 새 기하가
없으므로 125/150% 배율에서 갈릴 자리도 없다.

### 4. 못 하는 순간의 얼굴 — 잠그고, 그 옆에서 이유를 말한다. 둘 다 한다

**둘 중 하나가 아니다.** 이 저장소가 판정 창에서 이미 쓰는 답이 그것이다 —
`dialog.js` 의 `yes.disabled = …` 와 `.dlghint` 는 **함께** 선다: 못 누르게 하고, 왜 못
누르는지를 단추 옆에 글로 세운다.

- 눌리게 두고 실패 창을 띄우면 「눌러 봐야 아는 화면」이 된다 — 리드 제약 6 을 정면으로 어긴다.
- 잠그기만 하면 disabled 단추는 이유를 말하지 않아 「고장인가」가 된다.

**잠금은 `disabled` 가 아니라 `aria-disabled="true"`** 다 — REQ-20260831-009-62x6 가 깨우기
단추에서 세운 규율(`disabled` 는 포커스를 걷어 키보드 손을 body 로 떨어뜨린다). 과녁은
그대로 두고 손맛만 물러선다(`--muted` 잉크 + `--hairline` 보더, 색면 없음). 그래야 키보드
손이 잠긴 단추에 닿고, `aria-describedby` 로 묶인 사유 줄이 읽힌다.

**사유가 서는 자리 = 그 행의 뜻 줄 자리(`.wmean`).** 새 칸을 만들지 않는다. 즉 뜻 줄은
상태에 따라 얼굴을 바꾼다 — **열려 있으면 무엇을 하는지, 막혔으면 왜 못 하는지.** 색으로
가르지 않고 **문법으로** 가른다(`…합니다` ↔ `…해서 …할 수 없습니다`). 잠긴 단추의 잉크
농도가 그 위에 한 겹 더 얹힌다.

| 막는 것 | 어느 단추 | 사유 줄 (초안) |
|---|---|---|
| 도는 작업자 있음 | 올리기 (받기도) | `무인 작업 1건이 돌고 있습니다 — 끝난 뒤에 올릴 수 있습니다.` + `도는 일 보기` (`.more`, Board 로) |
| 작업 트리 더러움 | 받기 | `고치던 파일 2개가 있습니다 — 커밋하거나 되돌린 뒤에 받을 수 있습니다.` |
| 역사 갈라짐 | 둘 다 | `원격에도 여기에도 새 커밋이 있습니다 — 합치는 일은 화면이 하지 않습니다. 터미널에서 정리해 주세요.` |
| 올릴 것 없음 | 올리기 | `올릴 것이 없습니다 — 커밋한 것이 있어야 올립니다.` |
| 받을 것 없음 | 받기 | `받을 것이 없습니다 — 원격에 새로 올라온 것이 없습니다.` |
| 권한 없음 | 둘 다 | `저장소를 바꾸는 일은 admin 만 합니다.` |
| 남의 시점으로 보는 중 | 둘 다 | `지금 @user1 시점으로 보는 중입니다 — 내 시점으로 돌아가면 열립니다.` |
| 원격이 없음 | 둘 다 | `이 저장소에는 원격이 없습니다.` + 붙이는 명령 한 줄(미등록 계정 판이 `s9 user add` 를 적는 손버릇 그대로) |

사유는 **다음 행동을 준다** — 빈 상태 규율(안내가 아니라 다음 행동)의 재적용이다.
「고치던 파일」의 이름은 상태 줄이 이미 들고 있으므로(2절) 사유 줄은 **숫자만** 말한다 —
같은 목록을 두 번 적지 않는다.

**판정은 서버가 한다.** 화면이 네 조건을 다시 세면 규칙이 두 벌이 되어 언젠가 갈린다
(전이가 반드시 `do_transition` 한 문을 지나는 그 규율). 화면은 서버가 준
`can.pull{ok,why}` / `can.push{ok,why}` 를 **그대로** 그린다 — 「서버의 문장이 곧 팝업이다」
(REQ-20260901-018-62x6)의 연장. 그리고 누른 순간 서버가 **다시 판정한다**: 화면이 「없다」고
보여 준 사이에 작업자가 뜰 수 있다. 그 재판정은 「눌러 봐야 아는 화면」이 아니라 **경합의
마지막 문**이다.

### 5. 도는 중 · 끝난 뒤

**누르기 직전 — 올리기만 확인 창** (`s9dlg`, 네이티브 confirm 금지)

    {kind:"confirm", stop:true, cap:"올리기",
     title:"커밋 3개를 GitHub 으로 올릴까요?",
     descHtml: "origin/main 이 바뀝니다. 올린 것은 이 화면에서 되돌릴 수 없습니다."
             + "<div class='wsfix'>…커밋 제목(mono) 최대 5줄 + 「외 N개」…</div>",
     ok:"올리기", cancel:"그만두기"}

`stop:true` 는 022 의 gh 스위치와 같은 판단이다 — 되돌릴 수 없이 바깥으로 나가는 일.
**창 안에 올릴 커밋 제목을 보여 주는 것이 이 설계에서 가장 값싼 안전장치다**: 사람이
무엇을 내보내는지 보고 누른다. `.wsfix` 는 이미 있는 창 안 목록 자리이고, 5줄로 자르면
1531×684 에서도 세 띠가 안 잘린다(0절 캡처로 확인). 받기는 창이 없다.

**도는 중** — 몇 초 걸린다.

- 누른 단추: `.acts button.deed.busy` — **이미 있는 「숨」**(1.4s opacity 맥박,
  `prefers-reduced-motion` 대응 완료). 새 스피너를 만들지 않는다. 옅히기만 하면 잠긴
  단추와 구별이 안 된다(그건 「못 누른다」는 뜻이고 이건 「하고 있다」는 뜻이다).
- 라벨은 **바뀌지 않는다** — 폭이 흔들리면 레이아웃이 흔들린다.
- 다른 단추도 함께 잠기고 사유는 `지금 받는 중입니다.`
- `.wmsg`(이미 `role="status" aria-live="polite"`)가 **단계와 경과**를 말한다:
  `원격에 묻는 중… 2초` → `받는 중… 5초`. 정적 문구는 멈춘 것처럼 읽히므로 경과를 1초마다
  갱신한다. 30초를 넘기면 한 마디 더: `느립니다 — 원격이 응답하지 않을 수 있습니다.`
  (카드의 「오래 걸림」 규칙의 재적용.)
- **높이는 안 흔들린다** — `.wsay` 가 뜻 줄과 결과 줄을 같은 격자 칸에 겹쳐 두는 022 의
  해법을 그대로 물려받는다.

**끝난 뒤 — 결과는 두 자리에 살고, 수명이 다르다**

1. **그 행의 `.wmsg`** — `커밋 2개를 받았습니다.` **3초 뒤 뜻 줄로 되돌아온다**
   (사라지는 것이 아니다 · 022 규율 그대로). 즉각 피드백의 몫.
2. **상태 줄** — 서버 응답이 **새 상태를 함께 준다**(두 번 묻지 않는다). 상태 줄이 즉시
   다시 그려지는 것이 곧 「무엇이 바뀌었나」의 답이다: `원격과 같습니다`.
3. **무엇이 들어왔나** — 상태 덩이 아래 `.more` 텍스트 버튼 한 줄:
   `+ 방금 받은 커밋 2개 보기` → 펴면 mono 목록(짧은 해시 + 제목). **기본 접힘.**
   이 줄은 **다음 조작이나 탭을 떠날 때까지** 남고, 새로고침하면 사라진다 — 영속 기록은
   문서와 저장소 역사가 이미 들고 있으므로 화면이 세 번째 사본을 만들지 않는다.

**실패** — `.wmsg.bad`(`--c-blocked` 글자색)에 **서버가 준 문장 그대로**, 되돌아오지 않는다
(사람이 읽고 조치할 것이 남아 있다). 팝업 금지·인라인(`postJSONRaw` 의 그 규율). 뜻 줄
자리에는 다음 행동 한 줄이 선다(예: 올리기가 거절당하면 `먼저 받은 뒤에 다시 올려 주세요.`).
연결 끊김은 `서버에 연결할 수 없습니다` 가 이미 있다.

### 6. 권한 — 손잡이는 admin, 상태는 등록 사용자 모두

- **읽기(상태 줄·「지금 확인」)는 등록 사용자 모두.** 「읽기 = 자유」는 이 대시보드가 이미
  세운 규칙이고, 거리를 아는 데는 위험이 없다.
- **받기·올리기는 admin 만.** 근거 둘: ① 이 일은 내 계정의 설정이 아니라 **모두의
  저장소**를 바꾼다 — 「사용자 관리」가 admin 전용인 그 축이다. ② **누르는 사람과 서명하는
  계정이 다르다** — 올리기는 이 컴퓨터에 로그인된 GitHub 계정으로 나간다(022 의 gh 문장이
  이미 그 사실을 말한다). member 가 눌러도 바깥에 남는 얼굴은 그 계정이다. 화면이 남의
  이름으로 서명하게 두지 않는다.
- **대리(asUser)로 남의 시점을 볼 때는 둘 다 잠긴다.** 저장소를 바꾸는 일을 대리로 하지
  않는다 — 비밀 키가 대리를 안 받는 것과 같은 축.

### 7. 나머지 얼굴들

- **미등록 계정** — 「내 계정」·「무인 작업」이 쓰는 그 문장(터미널 등록 안내). 상태 줄은
  보여 준다(저장소는 계정과 무관하다).
- **목록을 못 받음** — 이미 있는 `다시 불러오기` 단추.
- **저장소가 아님 / 원격 없음 / 명령 없음** — 상태 문장 자리에 서버 문장, 단추 둘 잠김.
- **고치던 파일 500개** — 앞 3개 이름 + `+ 497개 더 보기`(`.more`), 펴도 50줄에서 자르고
  `…외 N개`. 무한 목록 금지.
- **올릴 커밋 200개** — 라벨 `커밋 200개 올리기`, 창 목록은 5개 + `외 195개`.
- **빈 상태는 없다** — 두 손잡이는 어떤 저장소에서도 늘 서고, 못 하면 사유를 말한다.

### 8. 서버에 요구하는 것 (설계가 정하는 계약 · 구현 몫)

- `GET /api/git/state?ask_remote=0|1` →
  `{branch, upstream, ahead, behind, dirty:[경로…], dirty_n, asked_at, remote_ok,
    workers:N, can:{pull:{ok,why}, push:{ok,why}}}`.
  **`can` 을 서버가 판정한다**(4절). `ask_remote=0` 이 기본 — 값싼 쪽만.
- `POST /api/git/pull` · `POST /api/git/push` → 같은 판정을 **다시** 하고, 통과하면 돌린다.
  응답 `{ok, said, commits:[{hash,title}], state:{…}}` — 실패는 `{ok:false, error:"<문장>"}`.
- 서버가 **아예 못 하게 짜인다**: 커밋하지 않는다 · 치워 두었다 되돌리지 않는다 ·
