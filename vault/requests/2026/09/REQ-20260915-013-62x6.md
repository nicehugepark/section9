- [ ] N1. 정상(서버): Windows 에서 /api/notices 의 미등록 계정 알림이 `bin\s9 user add <계정>` 을 싣는다 — 리눅스·맥·WSL 에서는 `s9 user add <계정>` 그대로
- [ ] N2. 정상(서버): 같은 규칙이 서버 옛 코드(`serve --restart`)·동기화(`sync`)·진단(`doctor`) 알림에도 적용된다 — 명령을 짓는 자리가 한 곳(s9_cmd)이다
- [ ] N3. 정상(화면): Settings 의 미등록 계정 안내 넷(내 계정·디스플레이·백그라운드 작업·에이전트·스킬)과 알림 줄의 문구가 whoami.os 를 따라 `bin\s9` 로 보인다
- [ ] N4. 경계: whoami 가 아직 안 왔거나 os 가 빈 값이면 종전 꼴(`s9 …`)로 — 화면이 비거나 undefined 가 새지 않는다
- [ ] N5. 회귀: 리눅스에서 지금 화면의 문구가 글자 그대로 그대로다(캡처로 확인) · notices_api·notice_rail 시험 통과
