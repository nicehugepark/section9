### 2026-09-15T13:23:25+09:00 response (agent: lead:claude-opus-5, by nicehugepark)

구현 — 명령을 짓는 자리를 둘로 모으고 서버의 OS 를 따르게 했다

**뿌리**: 화면과 서버가 s9 명령을 **글자로 박아** 두었다. 네이티브 Windows 에는 PATH 에 s9 가 없어 그 글자를 붙여 넣으면 실행되지 않는다 — 안내가 안내가 아니게 된다.

**고친 것**
- `bin/s9.py` `s9_cmd(rest)`: os_platform() 이 Windows 면 `bin\\s9 …`, 아니면 `s9 …`. 알림 줄의 명령 넷(미등록 계정·서버 옛 코드·동기화·진단)이 이것을 지난다.
- `web/app/state.js` `s9cmd(rest)`: whoami.os 를 보고 같은 판단. whoami 가 아직 없거나 os 가 비면 종전 꼴이라 화면이 비거나 undefined 가 새지 않는다.
- 문구 적용: Settings 미등록 안내 넷(내 계정·디스플레이·에이전트·스킬 + 알림 줄 「내 것만」 tooltip) · 선행 대기 빈 자리(`s9 link`) · 내 프로젝트 없음(`s9 project member add`) · 그래프 빈 화면(`s9 new request`) · 답 찾기 설명(`s9 note … --label answer`) · 신원 tooltip(`s9 user attach`).

**실측**(대시보드를 새 코드로 재시작한 뒤 chromium·webkit 둘 다)
- 미등록·Windows 로 세운 Settings 내 계정: 「… 터미널에서 **bin\\s9 user add 박성진** 으로 등록하세요. 다른 이름의 기존 계정에 연결하려면 **bin\\s9 user attach <이름>**.」 같은 화면을 linux 로 세우면 종전 글자 그대로.
- s9cmd 의 경계: os 가 빈 값·whoami 자체가 없을 때 모두 `s9 …` 로 떨어지고 오류가 없다.
- 여섯 화면(Board·Docs·Graph·Settings·Projects·Audit)에서 두 엔진 모두 콘솔 오류 0.
- 시험: notices_api 12건(새 2건 포함) · notice_rail · header_notice 35건 통과.
