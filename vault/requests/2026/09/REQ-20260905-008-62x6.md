## Notes

### 2026-09-05T17:11:04+09:00 response (agent: lead:claude-fable-5-1, by nicehugepark)

답: 그 창은 **윈도우의 Claude 데스크톱 앱**(`C:\Program Files\WindowsApps\Claude_1.46388.4.0_x64_…\app\claude.exe`, 스토어 패키지)이 띄운 것이다 — WSL 의 Claude Code 도, section9 도 아니다. 「ReadProcessMemory 또는 WriteProcessMemory의 일부 작업만을 마쳤습니다」는 윈도우 오류 299(ERROR_PARTIAL_COPY)로, 한 프로세스가 다른 프로세스의 메모리를 읽고 쓰다 절반만 성공했을 때 난다 — 스토어 앱이 **돌고 있는 채로 자동 갱신**될 때(실행 파일이 바뀐 뒤 옛 인스턴스가 새 것을 건드림) 흔히 보인다. section9 는 윈도우 쪽에서 powershell 로 포트 표를 읽고, 우리가 띄운 헤드리스 chrome 과 중계(dllhost)만 회수 후보로 본다 — claude.exe 를 건드리는 자리가 없고 오늘 회수 실행 기록도 0 이다(port-guard-ring recovers=[]). 시험과 같은 시각인 것은 우연이다. 다시 뜨면 Claude 데스크톱 앱을 껐다 켜면 되고, section9 상태 점검에는 필요 없는 정보다.
