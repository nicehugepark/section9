## Original

2026-09-15 맥 전체 테스트(3711건) 중 유일한 실패.

FAIL: test_no_third_party_imports (test_stdlib_only.TestStdlibOnly)
  ["bin/s9_firstrun.py: import winreg"]

원인: stdlib_names() 는 python 3.10+ 에서는 sys.stdlib_module_names 를 쓰지만(그 목록은
플랫폼과 무관하게 winreg·msvcrt·winsound 를 담는다) 3.9 이하에서는 파일 시스템을 훑어
만든다. 맥·리눅스 설치에는 Windows 전용 모듈의 파일이 없으니 그 이름이 빠지고, Windows
갈래 안에서 import 하는 bin/s9_firstrun.py:437 이 서드파티로 잡힌다. 이 머신의 python3 는
3.9.6 이라 이 갈래를 탄다(s9 doctor 도 같은 판을 경고한다). WSL(3.12)에서는 안 난다.

고칠 자리: tests/test_stdlib_only.py 의 stdlib_names() 폴백에 Windows 전용 표준 모듈
이름을 더한다(winreg · msvcrt · winsound · _winapi · nt · msilib). 회귀는 3.9 폴백이
그 이름들을 아는지 보는 시험 한 건.
