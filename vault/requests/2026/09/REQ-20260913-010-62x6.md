### 고칠 것 — 둘

**1. 「설치 파일」 (invite.html:108 · invite.txt:10)**
- 지금: `설치 파일을 받으세요.`
- 이렇게: `압축 파일을 받으세요.`
- 왜: 이 메일이 처음 지은 말인데(제품 어디에도 없다) 물건과 어긋난다 — Windows 에서 「설치 파일」은 두 번 눌러 마법사가 뜨는 `setup.exe`·`.msi` 를 뜻하고, 실제로 받는 것은 압축 파일이다. 바로 다음 줄이 「압축을 푼 다음」이니 같은 것에 이름이 하나로 이어진다.

**2. OS 이름 표기가 한 줄 안에서 두 벌 (invite.html:109·123 · invite.txt:11·14)**
- 지금: `리눅스와 맥은 tar.gz, Windows 는 zip 을 받으시면 됩니다.` / 라벨 `리눅스 · 맥 — 터미널`
- 이렇게: `Linux 와 macOS 는 tar.gz, Windows 는 zip 을 받으시면 됩니다.` / 라벨 `Linux · macOS — 터미널`
- 왜: 셋 다 제조사가 지은 제품명인데 둘만 한글로 옮겼다. 받는 사람이 `{{release_url}}` 페이지에서 다시 만나는 글자는 파일 이름의 `linux`·`macos`·`windows` 라, 로마자 한 벌이 그 화면과 맞는다(반대 방향 통일은 불가 — 「윈도우」는 반려감이다).

### PowerShell 만 적을지 — 병기하지 않는다

`Windows — PowerShell` 그대로 두십시오. ① 명령이 PowerShell 문법(`.\`·`$env:`·따옴표 규칙)을 쓰면 cmd 에서 그대로 돌지 않아, 병기는 용어가 아니라 **명령을 한 벌 더 짓는 일**이 됩니다(REQ-20260913-010-62x6 의 범위). ② 압축 푼 폴더에서 여는 기본이 PowerShell 입니다(Windows 11 터미널 기본 프로필, 탐색기 Shift+우클릭). ③ 초대 메일의 결정은 「합류」 하나이고, 고를 것이 늘면 결정이 늡니다.

용어 밖의 권고 하나(designer 판단): 라벨 아래 작은 글씨로 `시작 메뉴에서 PowerShell 을 열어 주세요` 한 줄. cmd 를 연 사람이 붙여넣고 실패하는 길을 막습니다.
