## Notes

### 2026-09-10T10:58:44+09:00 tdd (agent: lead:claude-fable-5-1, by nicehugepark)

갈래 — 결정: 판(.board)은 스크롤 상자로만 남기고, 열 여섯은 그 안의 `.cols` 한 상자가 flex 로 세운다. `.cols` 는 높이가 정해지지 않은 상자라 flex 줄의 높이가 가장 긴 열의 내용 높이가 되고(명세 §9.4), `min-height:100%` 로 판 높이보다는 작아지지 않는다(빈 열의 머리도 판 끝까지 남는다). 재는 값 없이 배치로 푼다.

### 정상
- [ ] N1 창 1280x800 에서 판을 끝까지 내려도 열 머리 넷이 판 윗변에 남는다 (dy ≤ 1.5)
- [ ] N2 열 여섯의 높이가 판의 스크롤 내용 높이와 같다 — 짧은 열도 긴 열만큼 선다

### 경계
- [ ] B1 뷰포트 380 에서 판을 끝까지 내려도 머리가 판 윗변에 남는다 (맥 실측이 129 로 떠난 자리)
- [ ] B2 내용이 판보다 짧을 때 열의 높이가 판의 안쪽 높이와 같다 — .cols 의 min-height:100% 가 산다

### 실패
- [ ] F1 스킨의 판 gap(calm 14·16 / soft 14)이 .cols 로 이어진다 — 열 사이 간격이 바뀌지 않는다

### 회귀
