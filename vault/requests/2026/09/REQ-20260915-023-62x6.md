## Original

주인 지적 2026-09-15 15:42 (대시보드 채팅, REQ-20260915-013-62x6 에 붙은 그림): 「화면의 가이드에 명령어 부분이 코드 구간으로 표시가 되면 좋겠다. 문장인지 명령어인지 구분이 되지 않는다.」

그림(Settings → 내 계정, 미등록 계정 안내): 「이 OS 계정(박성진)은 미등록입니다 — 터미널에서 bin\s9 user add 박성진 으로 등록하세요. 다른 이름의 기존 계정에 연결하려면 bin\s9 user attach <이름>.」 — 명령이 등폭으로 보이기는 하나 문장과 같은 줄을 그대로 흘러, 어디까지가 명령인지 경계가 없다.

닿는 자리는 REQ-20260915-013 의 N6 이 훑어 둔 목록이다: Settings 미등록 안내 넷(내 계정·디스플레이·백그라운드 작업·에이전트·스킬) · 알림 줄 · 선행 대기 빈 자리 · 내 프로젝트 없음 · 그래프 빈 화면 · 답 찾기 설명 · 신원 tooltip.
