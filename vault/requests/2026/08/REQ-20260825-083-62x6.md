대시보드 터미널 하단에 agent 가 선택이 안된다. 실제 실행 중인 에이전트인지, 화면 버그인지 점검해.

## Notes

### 2026-08-25T22:02:51+09:00 response (by nicehugepark)

점검 결과: 화면 버그가 맞다(그리고 그 행이 실제 실행 중인 에이전트라는 보장도 없다).
- 스트립은 두 경로로 그려진다. 서버 파싱 경로(`/api/agents`)는 `.ccagrow`+`data-agent`가 붙어 클릭 시 termAgentOpen으로 열린다. 폴백 경로(transcript 근사 `T.agents`)는 `<div class="ag sub">`만 그려서 **클래스도 data-agent도 없다 → 클릭 핸들러가 잡을 대상이 아예 없다**. 스크린샷의 `agent … running` 행이 이 폴백이다(타입이 실제 에이전트명이 아니라 그냥 `agent`인 것이 근거).
- 왜 폴백으로 떨어졌나: `/api/agents`는 응답하지만 `active`는 mtime 180초 이내만 참이라, 종료된 에이전트만 남으면 활성 0건이 되고 화면은 근사 목록을 그린다. 근사 목록은 `termAgentDone`이 "가장 오래된 활성분"을 지우는 방식이라 실제 종료와 어긋나 유령 행이 남는다.
수리 방향: (1) API가 정상 응답하면 서버 목록만 신뢰(활성 0건이면 아무것도 그리지 않는다) — 근사 폴백은 API 부재(구버전 serve)일 때만, (2) 폴백 행은 열람 불가임이 보이도록 표기. web/index.html은 지금 스킨 점검 에이전트가 수정 중이라 그 작업이 끝난 뒤 적용한다.

### 2026-08-26T00:22:59+09:00 designer (by nicehugepark)

수리 완료 (web/index.html). 원인 규명 노트의 두 방향을 그대로 구현했다.

1) 서버 목록이 정상 응답한 적이 있으면 그 뒤로는 서버만 신뢰한다. agTick에서 /api/agents 응답을 받는 순간 T.srvAgentsOk=true (sticky — 일시적 타임아웃으로 유령 폴백에 되떨어지지 않게). termAgentsRender는 srvAgentsOk이면 활성 0건일 때 스트립을 비운다. 스크린샷의 "○ agent … running" 유령 행이 여기서 사라진다.
2) 폴백(구버전 serve, 목록 API 자체가 없을 때)은 열람 대상이 아님을 행에 쓴다. .agapx 클래스 = opacity .6 + cursor:default, 우측 표기를 "running"(단언) 대신 "추정 · 열람 불가"로 바꾸고 title에 이유를 넣었다. 상태를 모르면서 running이라고 쓰지 않는다.
3) 애초에 "선택이 안 된다"고 느낀 이유 하나 더 — 열 수 있는 행과 못 여는 행(main/transcript)이 똑같이 생겼다. 포인터를 올리면 우측 메타 끝에 " · 열기"가 붙어 클릭 대상임을 글자로 확인시킨다(.ccagrow:hover .r::after). 평소엔 조용하다.

검증: 터미널 탭은 SSE가 끊기지 않아 headless 캡처가 60초 타임아웃으로 절대 정착하지 않는다(2회 실측). 그래서 index.html의 <style> 전문과 termAgentsRender 함수 본문을 그대로 추출한 하네스 페이지를 만들어 세 상태를 한 화면에 렌더해 캡처했다 — /home/sjpark1/section9/state/shots/req081/f3-agentstrip.png (① 서버 목록·활성 2건 = 굵은 이름 + data-agent 행 ② 서버 목록·활성 0건 = 유령 행 없음 ③ 폴백 = 흐린 "추정 · 열람 불가"). 하네스 파일은 캡처 후 제거했다.
미검증으로 남긴 것: 실제 라이브 세션에서 에이전트가 뜨고 지는 동안의 전이(폴 주기 10초)와 클릭 시 termAgentOpen 열람. 리드가 브라우저에서 터미널 탭을 열고 F5 후 확인해 주기 바란다.

주의(동시 작업): 같은 함수에 staff의 지목 전송 버튼(.agtgt "→")이 들어와 있다. 내 hover 힌트는 화살표 충돌을 피해 "← 열기"에서 " · 열기"로 바꿨다.
