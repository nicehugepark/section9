그리고 클램프 자체가 **calm 한 벌에만** 있었다 — ledger·glass·terminal·field·cork 등에서는 확인 포인트가 통째로 실려 review 열이 글자 벽이었다.

고친 것 넷:
① 확인 요청·대기 사유 본문을 **세 줄**에서 자른다. 베이스 CSS 라 스킨 열 벌 전부에 적용된다. 배경 줄(무엇을) 2줄 + 확인 요청 3줄 = 판정 블록 다섯 줄 상한 → 카드 높이에 천장이 생겨 열의 리듬이 서고, 승인·반려 버튼이 긴 글에 밀려나지 않는다.
