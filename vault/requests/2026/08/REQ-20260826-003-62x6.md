## Original

아키텍트 조사(2026-08-26) 격리 재현으로 확인된 차단급 결함 2건. 인스턴스에 sync를 켜기 전에 반드시 선행해야 한다.

결함 A — 스테이징된 코드가 sync 커밋에 휩쓸린다: sync_run은 데이터 경로만 add한 뒤 pathspec 없이 git commit을 호출해 인덱스 전체를 커밋한다. admin이 WIP 코드를 stage 해둔 채 문서를 하나 만들면 미완성 코드가 origin에 푸시된다(재현: bin/fake_code.py가 sync 커밋에 실려 나감).

결함 B — non-admin은 보호경로를 stage 하는 순간 sync가 전면 정지한다: git commit이 pre-commit(s9-guard)을 실행해 거부당하고, 문서가 로컬에도 커밋되지 않는다. s9 new는 rc=0으로 성공을 보고하고 실패는 아무도 읽지 않는 state/sync.log에만 남는다 — 무증상 데이터 미동기화.

수정 방향: git commit --only -- <데이터경로> 로 커밋 범위를 한정한다. 하나의 수정으로 A와 B가 함께 닫힌다. --no-verify로 훅을 우회하지 마라 — s9-guard는 인가 경계지 장애물이 아니다.

동봉 결함 C — 대시보드 첨부 ingest가 s9 new 서브프로세스 뒤에 실행돼 그 sync 사이클을 놓친다(bin/s9:1849 부근). 첨부는 다음 문서 이벤트에 묻어가고, 후속 이벤트가 없으면 로컬에만 남는다.

동봉 결함 D — tests/test_s9_sync.py에 tearDownClass가 없어 실행마다 /tmp에 임시 디렉토리를 누출한다.

TDD 시나리오(착수 시 확정): WIP 코드를 stage 한 상태의 sync 커밋에 코드가 포함되지 않는다 / non-admin이 보호경로를 stage 해도 문서 커밋·푸시가 성공한다 / 첨부가 생성과 같은 사이클에 실린다 / 테스트가 임시 디렉토리를 남기지 않는다.

### 2026-08-26T02:30:01+09:00 response (by nicehugepark)

결함 4건 모두 닫았다. 커밋 fa56c10. 전체 스위트 401건 green.

**A — 스테이징된 코드가 실려 나감.** 커밋 범위를 데이터로 한정했다. 다만 지시대로 `commit --only -- <데이터 디렉토리>` 를 그대로 쓰면 **전체가 깨진다** — 통째로 무시(.gitignore)되는 경로 하나가 섞이면 "pathspec did not match" 로 커밋이 죽는다(스위트 5건이 그렇게 빨갛게 됐다). 그래서 디렉토리가 아니라 **실제로 스테이징된 데이터 파일 목록**을 `diff --cached --name-only` 로 뽑아 지목한다. 남이 stage 해둔 코드는 손대지 않고 그대로 남는다(테스트로 고정).

**B — non-admin 무증상 정지.** 범위를 좁히니 pre-commit 거부는 사라졌는데, 거기서 끝내면 안 됐다. 다음 단계인 `pull --rebase` 가 "인덱스에 커밋 안 된 변경이 있다"며 거부해서, 문서는 로컬 커밋까지만 되고 origin 에는 못 갔다 — 겉보기엔 성공이라 종전과 똑같은 무증상 미동기화다. `--autostash` 로 닫았다. 훅은 우회하지 않았다(지시대로 --no-verify 금지).
이건 테스트가 없었으면 못 봤다. 커밋 범위만 고치고 "로컬 커밋 되니까 됐다"로 끝났을 것이다.

**C — 첨부가 사이클을 놓침.** 대시보드 경로만이 아니라 `s9 assets ingest` CLI 에도 같은 구멍이 있었다. 호출부마다 동기화를 기억하게 두면 또 새는 자리가 생기므로, **옮기는 쪽(ingest_assets)에서 한 번** 돌게 했다.

**D — 임시 디렉토리 누수.** tearDownClass 추가. 쌓여 있던 11개(약 20MB) 회수했고 재실행 후 0이다. 방금 닫은 REQ-002 와 같은 부류라 함께 처리했다.

검증: TDD 시나리오 3건을 먼저 빨갛게 재현하고 고쳤다 — Y7(스테이징 코드 미포함 + 그 코드가 stage 상태로 보존됨), Y8(보호경로 stage 상태에서도 origin 까지 도달), Y9(첨부가 같은 사이클에 실림). 기존 Y1~Y6 회귀 포함 9/9.
