### 2026-08-29T01:47:35+09:00 response (by nicehugepark)

구현 — 러너가 인자를 전부 패턴으로 받는다 (tests/__main__.py).

patterns(argv): 인자마다 'tests/' 접두·'.py' 접미·'test_' 접두를 벗겨 test_*<조각>*.py 로 만든다. 인자가 없으면 test_*.py 하나.
discover(pats): 패턴마다 discovery 를 돌려 합치되 테스트 id 로 중복을 제거한다(두 번 도는 것은 낭비이고, 상태를 쓰는 테스트는 두 번째가 첫 번째의 잔재를 본다). 반환에 '아무것도 못 고른 패턴' 목록을 함께 준다.
main(): 못 고른 패턴이 있으면 이름을 대고 종료코드 1 — 고른 것이 전부 통과해도 그렇다. 이게 이 건의 핵심이다.

실측 대조 — 게이트가 실제로 쓰는 호출 형태:
  전: python3 tests/ commit_gate streams_untracked → Ran 10 (commit_gate 만)
  후: python3 tests/ commit_gate streams_untracked → Ran 19 (둘 다)
  python3 tests/ uid 없는것zzz → 'no tests matched: test_*없는것zzz*.py' + rc=1
  python3 tests/ uid → rc=0

시험: tests/test_runner_patterns.py 10개 — 인자 세 형태, 여러 패턴 수집, 중복 제거, 못 고른 패턴 지목, 프로세스 경계에서의 종료코드, 그리고 s9-guard 가 만드는 이름 목록이 러너에서 전부 선택되는지(끝에서 끝까지).
