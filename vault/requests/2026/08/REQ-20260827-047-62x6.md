**내가 할 수 있는 것**: `gh` 가 이 계정으로 인증돼 있어서 API 로
`allow_force_pushes` 를 잠시 true 로 바꾸고, push 하고, 되돌릴 수 있다. 세 번의
호출이고 전부 되돌릴 수 있다.

**하지 않고 묻는 이유**: 이 보호 규칙은 **사용자가 일부러 걸어 둔 것**이다(PR 승인
1건 + 강제 푸시 금지 + 브랜치 삭제 금지 — 기본값이 아니다). 승인받은 것은 "푸시"이지
"보호를 잠시 푸는 것"이 아니다. 되돌릴 수 있다는 것과 물어보지 않아도 된다는 것은
다르다 — 되돌리는 단계가 실패하면 리포가 열린 채로 남는다.

**둘 중 하나로 진행한다**
1. 내가 한다: allow_force_pushes → true → push → false 로 복구 → 복구 확인까지 보고
2. 사용자가 GitHub 화면에서 Settings → Branches → main 규칙의 "Allow force pushes"
   를 잠깐 켜고, 내가 push 한 뒤 다시 끈다

로컬은 그대로 대기 중이다 — 재작성 완료, 13MB, `backup-before-rewrite` 보존 중.
