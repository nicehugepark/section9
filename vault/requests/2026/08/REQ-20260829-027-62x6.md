### `bin/s9` 에 필요한 것 — 리드가 적용 (한 갈래 삽입, 기존 줄 무수정)

화면이 뜨려면 서버가 `web/css/*.css` 와 `web/app/*.js` 를 내줘야 한다. 지금은 404 다.
**기존 줄을 하나도 고치지 않는 순수 삽입**이라 다른 작업과 글자로 부딪히지 않는다.

자리: `do_GET` 안, 정적 html 갈래(`elif re.fullmatch(r"/[\w.-]+\.html", ...)`) 의
`else: self._send(404, "text/plain", b"not found")` **바로 다음 줄**
(그 아래가 `# 가시성 필터는 응답 직전에만` 주석 + `/api/serveinfo` 갈래다).

```python
            elif re.fullmatch(r"/(?:app|css)/[\w.-]+\.(?:js|css)",
                              parsed.path or ""):
                # 화면 조각 (REQ-20260829-027-62x6). web/index.html 이 갈라져
                # web/css/*.css 와 web/app/*.js 를 부른다. 위 html 길과 **같은
                # realpath 규율**이다 — 접두 검사만으로는 심링크가 새 나간다.
                #
                # MIME 은 정확해야 한다: 스타일시트를 text/html 로 내주면 표준
                # 모드 브라우저가 그것을 **거부한다**. 조각을 .html 로 위장해
                # 이 갈래를 아예 만들지 않는 우회가 성립하지 않는 이유다.
                sub, _, base = parsed.path.strip("/").partition("/")
                home = os.path.realpath(os.path.join(ROOT, "web", sub))
                fp = os.path.realpath(
                    os.path.join(home, os.path.basename(base)))
                if os.path.dirname(fp) == home and os.path.isfile(fp):
                    ctype = ("text/javascript" if fp.endswith(".js")
                             else "text/css")
                    with open(fp, "rb") as f:
                        self._send(200, ctype + "; charset=utf-8", f.read())
                else:
                    self._send(404, "text/plain", b"not found")
```

이 갈래가 들어가면 `tests/test_web_split.py` 의 `Served` 4개(S6·S6b·S6c·S6d)가 초록이
된다. 지금은 S6d(옆문 차단)만 통과하고 셋이 빨강이다 — **그 빨강이 이 패치의 인수
조건**이다. 캐시 헤더는 `_send` 가 이미 `no-store` 라 화면이 즉시 바뀐다(정적 파일은
매 요청 디스크에서 읽으므로 `running_code_stamp` 에 더할 것이 없다).

### 시험은 어떻게 옮겼나 — 계약은 한 글자도 안 바꿨다

`tests/webasset.py` 하나가 조각을 **브라우저가 받는 한 장**으로 되돌린다
(`<link>` 묶음 → `<style>…</style>`, `<script src>` 묶음 → `<script>…</script>`).
시험 81개에서 바뀐 것은 **경로를 얻는 줄 하나뿐**이다:
`INDEX = os.path.join(HERE, "..", "web", "index.html")` → `INDEX = index_path()`.
`open(INDEX)` 도, 그 뒤의 정규식도, 단언도 그대로다. 이어 붙이는 규칙이 두 벌이
되지 않게 도우미는 하나로 두었다 — 갈라지면 시험들이 서로 다른 화면을 본다.
