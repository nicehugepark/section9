def resolve_id(doc_id):
    """id → 후보 uid 목록 (REQ-20260825-031, git 짧은 해시 원리).
    정확 일치(레거시 포함)가 최우선 — 있으면 그 1건만. 아니면 짧은 지칭
    (지문 없는 date형)을 uid prefix로 해석해 후보 전부를 돌려준다."""
    rows = load_catalog()
    exact = [r for r in rows if r["id"] == doc_id]
    if exact:
        return exact[:1]
    return [r for r in rows if r["id"].startswith(doc_id + "-")]
```

- **반환 자료구조**: 문자열이 아니라 `load_catalog()`가 읽은 **카탈로그 행(dict) 리스트**(`index/catalog.jsonl`의 각 줄, `id`/`path`/`title`/`status`/`session`… 키 포함). 항상 리스트이며, 원소 개수는 0/1/N.
- **짧은 id 입력 시 동작**: 먼저 `doc_id`가 카탈로그 `id`와 정확히 일치하는 행이 있으면(레거시 uid-없는 문서는 짧은 형태 자체가 전체 id라 여기서 잡힘) 그 1건만 반환. 없으면 `doc_id + "-"` 접두 매치를 **전부** 반환 — `REQ-20260825-080-62x6`을 넣으면 `REQ-20260825-080-62x6`가 이 조건에 걸려 후보로 나온다(git 짧은 해시 방식). 후보가 2건 이상(동일 날짜·순번을 서로 다른 머신이 발번)이면 모호 상태로 전체 후보가 반환된다.

def normalize_ids(text, known=None):
    """본문 속 short id(REQ-044, DOC-3 등)를 full id(REQ-20260823-044)로 확장.
    - 이미 full(PREFIX-YYYYMMDD-NNN)인 것은 안 건드린다.
    - 확장 후보가 정확히 1개일 때만 확장(0개·2개+ 애매하면 원본 유지).
    반환: (정규화된 text, [(원본, 확장)] 변경 목록)."""
    if not text:
        return text, []
    if known is None:
        known = _all_doc_ids()
    # 접미 3자리 → 후보 full id들 (같은 prefix). uid(지문 접미)도 수용 (REQ-031)
    by_suffix = {}
    for fid in known:
        m = re.match(r"^(REQ|DOC|SES)-\d{8}-(\d{3,})(?:-[0-9a-z]{4})?$", fid)
        if m:
            by_suffix.setdefault((m.group(1), m.group(2)[-3:].zfill(3)),
                                 []).append(fid)
    changes = []
    # short 패턴: PREFIX-<1~3자리>, 단 뒤에 -나 숫자가 이어지면(=full) 제외
    def repl(mo):
        prefix, num = mo.group(1), mo.group(2)
        suf = num.zfill(3)
        cands = by_suffix.get((prefix, suf), [])
        if len(cands) == 1:
            changes.append((mo.group(0), cands[0]))
            return cands[0]
        return mo.group(0)  # 0개·2개+ = 애매 → 유지
    out = re.sub(r"\b(REQ|DOC|SES)-(\d{1,3})(?![\d-])", repl, text)
    # 지문 없는 date형(레거시 표기·짧은 지칭)이 유일한 uid를 가리키면 전문으로
    def repl_date(mo):
        base = mo.group(0)
        if base in known:
            return base  # 레거시 정확 일치 — 그대로
        cands = [fid for fid in known if fid.startswith(base + "-")]
        if len(cands) == 1:
            changes.append((base, cands[0]))
            return cands[0]
        return base
    out = re.sub(r"\b(?:REQ|DOC|SES)-\d{8}-\d{3,}\b(?!-[0-9a-z])", repl_date,
                 out)
    return out, changes
```
**관계**: `normalize_ids`는 `resolve_id`와 별개의 (텍스트, 변경목록) 반환형이며, **자유 텍스트(History 노트 등)** 안에 섞인 짧은 REQ 언급을 확장하는 용도다. `resolve_id`/`locate`/`find_path`는 **구조적 id 인자**(CLI의 `id` 위치 인자)를 다루는 용도다. 이 둘은 서로 호출하지 않는다 — `normalize_ids`는 `_all_doc_ids()`(카탈로그 id 집합 또는 파일 스캔)를 쓰고, `resolve_id`는 `load_catalog()`를 직접 쓴다.

**핵심**: `normalize_ids`는 `do_transition()`에서 **`note` 파라미터에만** 적용된다(`bin/s9:937` `note, _ = normalize_ids(note)`). **`doc_id` 자체, 즉 `active_reqs`/`last_req`에 최종적으로 저장되는 문자열에는 어디서도 적용되지 않는다.** 짧은 id를 정규화하는 기계장치는 이미 존재하지만, 하필 이 값에는 배선이 안 돼 있다.
