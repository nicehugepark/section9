## Original

증상: docs/guide.md 8장 「자주 묻는 것」의 문답 열 개가 한 문단으로 붙어 읽을 수 없었다(2026-09-13, REQ-20260913-017-62x6 작업 중 발견).
원인: bin/s9-guide-md 의 handle_starttag 는 p·h1~h4·li·pre·table 에서만 줄을 바꾸고 div 는 지나친다(BLOCK 집합은 정의만 있고 쓰이지 않는다). div.faq > div.q / div.a 는 그래서 앞 문단에 그대로 이어 붙는다.
처방: 문단으로 갈려야 할 글은 html 에서 <p class="q"> / <p class="a"> 로 쓴다 — CSS 는 class 로 잡으므로 화면은 그대로다(.faq p{margin:0} 한 줄만 더했다). 생성기를 고치는 길(div 에도 nl)은 표·step 등 다른 div 의 md 모양을 함께 바꾸므로 별도 요청으로.
함께 알아 둘 것: s9 code --help 는 claude 의 도움말로 넘어가므로 s9 code 의 옵션은 bin/s9.py 의 add_parser("code") 를 읽어야 한다 · s9 secret set 은 값을 stdin 으로만 받는다(printf %s "<값>" | s9 secret set KEY) · 가이드 안의 명령 존재 확인은 grep -oE "s9 [a-z-]+" 로 뽑아 bin/s9 <명령> --help 를 돌리면 1분 안에 끝난다.
