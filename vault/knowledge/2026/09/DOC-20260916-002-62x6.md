## 왜 이 목록이 있나

규칙이 글로만 있으면 **에이전트는 읽은 말을 되쓰지만 지키지는 않는다.** 이
저장소의 이력이 그것을 세 번 보였다 — 규약 12조 「review 는 담긴 것만 올린다」는
**세 번째** 사고에서야 전이가 막았고, 그다음 날 바로 옆 구멍(가지에 담은 것이
main 에 안 닿는다)으로 같은 일이 또 났다.

그래서 규율마다 한 줄로 적는다: **막는 장치가 있나. 없으면 왜 없나.**
「없다」가 부끄러운 것이 아니라, 없다는 것을 **모르는** 것이 사고를 만든다.

## 목록 (2026-09-16 현재)

| 규율 | 막는 장치 | 비고 |
|---|---|---|
| 2조 비유·용어 | **있다** (경고) | `s9 note`·`status --note`·리드 응답·commit-msg 훅이 짚는다. 소스는 `test_no_metaphors` 가 지킨다 |
| 4조 TDD 먼저 | **있다** (차단) | `-> review` 가 TDD 미완료를 거부한다 |
| 5조 계보 | **있다** (차단) | `test_no_orphan_requests` · 착수·전이가 짚는다 |
| 12조 담긴 것만 review | **있다** (차단) | `-> review` 가 미커밋 코드를 짚어 거부 |
| 12조 가지가 main 에 닿기 | **있다** (차단+자동) | `-> review`·`-> done` 이 옮기고, 못 옮기면 거부 |
| 13조 goal 의무 | **있다** (차단) | goal 없으면 done 거부 |
| **13조 goal 근거의 질** | **있다** (경고, 오늘 세움) | 「시험 N건 통과」뿐이면 짚는다 — goal 자체가 시험이면 안 짚는다 |
| **17조 실패를 읽기 전에 다시 걸기** | **있다** (경고, 오늘 세움) | 거부 뒤 **고친 것 없이** 같은 것을 다시 걸면 짚는다 |
| HEAD 가 가지에 붙어 있기 | **있다** (자동+critical) | 당기기 전에 되붙이고, doctor 가 critical 로 말한다 |

| 18조 size 예산 | **없다** | size 는 리드의 처리 예산이고 코드가 분기하지 않는다(REQ-20260909-074 의 판정) — 예산은 위임 지시문과 절차 상한이 지킨다 |
| 7조 위임 반쪽을 파생 REQ 로 | **없다** | 위임 지시문은 훅이 읽지만 「…는 리드가 한다」를 읽고 자식 REQ 유무를 대조하는 자리가 없다 |
| 7조 화면에 넷+PO 소집 | **없다** | 누가 섰는지는 `agents:` 에 쌓이지만 「화면 요청인가」를 기계가 모른다 |
| 12조 리드 자가판정 | **없다** | 「사람만 아는 것이 들어가는가」는 기계가 못 가른다. 매 턴 주입이 대신한다 |
| 맥 Safari 확인 | **없다** | 다른 컴퓨터의 사실이라 이 컴퓨터가 알 수 없다. `--needs-machine` 요청이 대신한다 |

## 세우는 값이 있는 것과 없는 것

**세울 값이 있는 것**(다음 라운드 후보): 18조 「전체 테스트 마지막 한 번」 —
러너가 요청 id 를 알면 셀 수 있다. 7조 「위임 반쪽」 — 지시문에 「리드가」가
있는데 그 REQ 의 자식이 안 늘면 짚을 수 있다.

**세우지 않는 것**: 「사람만 아는 것인가」·「화면 요청인가」·「맥에서 봤는가」는
기계가 가를 수 없는 판정이다. 못 가르는 것을 억지로 세우면 옳은 자리까지 막고,
막히는 순간 사람은 우회를 찾는다. 그 셋은 주입과 요청으로 남긴다.

## 규율 하나

**막지 말고 짚어라** — 오늘 세운 둘은 경고일 뿐이다. 막는 것은 「그 자리에서
반드시 고쳐야 하고, 고칠 길이 분명할 때」뿐이다. 그 밖에는 짚고 지나가게 둔다.
