## 요지 (REQ-20260915-006-62x6, 2026-09-15 실측)
- **.lnk 는 Python 만으로 못 만든다.** PowerShell 의 `(New-Object -ComObject WScript.Shell).CreateShortcut(<경로>)` 에 TargetPath·WorkingDirectory·IconLocation('<ico>,0')·Description 을 넣고 Save(). 본문은 `powershell -NoProfile -NonInteractive -ExecutionPolicy Bypass -EncodedCommand <UTF-16LE base64>` 로 넘긴다 — 따옴표·한글 경로를 셸 인용에 맡기지 않는다. 구현: bin/s9_firstrun.py ensure_shortcuts.
- **바탕화면·시작 메뉴의 자리는 `%USERPROFILE%\Desktop` 을 못박지 않는다.** HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders 의 Desktop·Programs(REG_EXPAND_SZ, 이 컴퓨터 실측값 `%USERPROFILE%\Desktop` · `%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs`)를 winreg 로 읽어 ntpath.expandvars 로 편다 — OneDrive 가 바탕화면을 옮긴 계정은 값이 다르고, 시험이 USERPROFILE 을 임시로 돌리면 그대로 따라온다. winreg 가 없는 판(리눅스 시험)은 기본값을 편다.
- **탐색기 두 번 누르기의 재현**(WSL 에서): `cmd.exe /c <run.cmd>` 안에서 환경(set …)을 두고 `start "" /wait cmd /c ""C:\…\section9.cmd" < enter.txt > run.log 2>&1"` — 새 콘솔 창이 뜨고 출력은 파일로 남는다. stdin 을 파일로 주지 않으면 `s9 code` 의 이름 물음(input)이 그 창에서 사람을 기다려 /wait 가 돌아오지 않는다. WSL→Windows 의 env 전달은 WSLENV 가 필요하므로 run.cmd 안에서 set 한다.
- **콘솔 창이 닫혀도 서버가 남는지**는 Windows 쪽 `curl.exe http://127.0.0.1:<포트>/api/serveinfo` 로 본다(WSL 의 127.0.0.1 은 다른 쪽). 실측: `s9 code` 가 띄운 감시자·서버는 실행 파일의 창이 저절로 닫힌 뒤에도 답했다. 남은 창은 `tasklist /V /FI "WINDOWTITLE eq section9*"`, 남은 프로세스는 `Get-CimInstance Win32_Process` 의 CommandLine 으로 찾는다(wmic 은 없을 수 있다).
- **cmd.exe 배치의 규칙**: ASCII 만(콘솔 코드페이지로 읽는다) · CRLF(LF 만이면 라벨 이동 실패) · 실패 때 창을 붙드는 것은 `if not "%RC%"=="0" ( … pause )` — 정상 종료 길에 pause 를 두면 매번 키를 눌러야 한다. 종료 코드는 `endlocal & exit /b %RC%`.
- **HEAD 에 아직 없는 새 파일을 배포판 시험에 넣는 법**: 임시 index(GIT_INDEX_FILE)로 `read-tree HEAD` → `update-index --add -- <경로>` → `write-tree` 한 tree 를 `s9-release --ref <tree>` 에 준다. HEAD 로만 지으면 처음 담는 commit 의 pre-commit 검사가 옛 HEAD 를 보고 「없다」로 선다.
