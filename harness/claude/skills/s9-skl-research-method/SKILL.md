# Research Method

- 질문을 먼저 고정한다: "무엇을 알면 끝나는가"를 한 문장으로. 조사 중 확장되면 파생 질문으로 분리.
- 증거 계층: 1차(코드/로그/원문) > 2차(문서) > 3차(추측/기억). 결론에 어떤 계층 증거인지 표시.
- 모든 주장에 출처(파일:라인, 문서 id, 명령 출력)를 단다. 출처 없는 문장은 가설로 표시.
- 반증을 먼저 시도한다: 가설이 서면 그것을 깨는 증거를 한 번 찾아본 뒤 채택.
- section9 탐색 순서: digest → catalog(ls/search) → 문서 메타 → 본문 → 스트림(streams/). 전체 읽기는 최후 수단.
- 산출물: 질문 → 답 → 근거 → 확신도(높음/중간/낮음) → 남은 미지수. 이 구조를 벗어나지 마라.
