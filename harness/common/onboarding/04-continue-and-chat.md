## Original

진행 중인 요청에 덧붙일 말이 있을 때 — 「그 화면은 이렇게 바꿔줘」 「아까 그것 아직이야?」 — 새 요청으로 세우면 기록이 갈라집니다. 카드의 **이어 말하기** 는 다음 메시지를 그 문서에 이어 붙이는 손잡이입니다. 대시보드 안의 채팅(Terminal 탭)이 그 말을 실행 중인 세션으로 보내고, 그 말은 요청 문서에 기록됩니다.

### 이어 말하기의 자리 셋

| 어디 | 글자 |
| --- | --- |
| Board 의 카드 — REQ 번호 오른쪽 | **이어 말하기** |
| 문서 화면 — 위쪽 버튼 줄의 오른쪽 끝 | **이어 말하기** |
| Terminal 탭의 대화 속 REQ 번호를 눌렀을 때 뜨는 미리보기 | **이어 말하기** · **문서 열기** |

누르면 Terminal 탭으로 가고, 입력창 위에 **→ REQ-… 「제목」에 남깁니다** 와 **× 해제** 가 섭니다. 이 줄이 있는 동안 보내는 메시지는 그 문서로 갑니다. 골라 둔 카드에는 표시가 붙고, 「이어 말하기」를 다시 누르면 놓습니다. **× 해제** 를 누르면 다음 메시지부터 다시 새 요청으로 남습니다.

### Terminal 탭 읽는 법

- 위: 지금 실행 중인 세션의 화면 — 사용자의 말, 타치코마의 응답, 도구 호출(⚒), 결과.
- 아래: 입력창. Enter 전송, Shift+Enter · Ctrl+Enter 줄바꿈, `/` 로 시작하면 명령, 이미지는 붙여넣기나 드래그. 입력창 오른쪽의 「파일 첨부」 버튼(클립 모양)으로 그림 · 문서 · 로그를 붙입니다.
- target 줄: 어느 세션에 보내는지(세션 번호 · @사용자)와 그 세션이 실행 중인지. 세션 번호를 누르면 다른 세션을 고를 수 있습니다.
- 맨 아래 띠: 지금 타치코마가 위임해 일하고 있는 역할 에이전트와 각자의 경과 시간.

세션이 끝나 있으면 입력창이 그렇게 말합니다 — 「이 세션은 끝났습니다 — … target 을 눌러 실행 중인 세션을 고르세요」. 실행 중인 세션이 없으면 터미널에서 `bin/s9 code`(Windows 는 `bin\s9 code`)로 하나 엽니다.

### 따라 해 보기

1. Board 에서 이 카드(안내 4)의 **이어 말하기** 를 누릅니다. Terminal 탭이 열리고 입력창 위에 「→ REQ-… 「안내 4 — 이어 말하기와 채팅」에 남깁니다」가 섭니다.
2. 입력창에 「이 안내를 읽었습니다」를 치고 Enter.
3. Board 로 돌아와 이 카드를 눌러 문서를 엽니다 — 방금 보낸 한 줄이 이 문서에 남아 있고, 새 카드는 생기지 않았습니다.
4. Terminal 탭에서 **× 해제** 를 누릅니다 — 다음 메시지부터 다시 새 요청으로 남습니다.

### 끝내기

다 해 봤으면 이 카드를 끝내십시오 — 카드를 눌러 문서를 열고 **→ in-progress** → **상태 옮기기**, 이어서 **→ done** → **상태 옮기기**. 카드가 DONE 열로 갑니다(안내 1의 「끝내기」와 같습니다).
