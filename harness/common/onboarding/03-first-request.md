## Original

section9 에서 요청을 「등록」하는 일은 없습니다. 터미널에서 Claude Code 에게 평소처럼 일을 시키면, 훅이 그 말을 요청 문서(REQ)로 기록하고 Board 에 카드로 세웁니다. 여러분이 할 일은 말하는 것뿐입니다.

### 말이 카드가 되는 자리 둘 — 같은 세션입니다

| 자리 | 어디 | 어떻게 |
| --- | --- | --- |
| 터미널 | `bin/s9 code`(Windows 는 `bin\s9 code`)로 연 Claude Code 화면 | 프롬프트에 한 문장을 치고 Enter |
| 대시보드 | 상단 탭 **Terminal** — 위는 지금 실행 중인 세션의 화면, 아래는 입력창(안내 글자 「메시지 — Enter 전송 · Shift+Enter·Ctrl+Enter 줄바꿈 · / 명령 · 이미지 붙여넣기/드래그」) | 입력창에 치고 Enter. 입력창 위의 target 줄이 어느 세션(세션 번호 · @사용자)으로 가는지 말합니다 — `s9 code` 로 연 세션이 첫 순위입니다 |

터미널 창을 닫고 나왔어도 Terminal 탭에서 같은 세션에 이어 말할 수 있습니다.

### 무엇이 카드가 되고 무엇이 안 되나

| 이렇게 치면 | 이렇게 됩니다 |
| --- | --- |
| 「결제 모듈에 환불 API 추가해줘」 | 요청 — REQ 카드가 OPEN 열에 서고(화면에 기록 안내가 뜹니다), 타치코마가 착수하면 IN-PROGRESS 로 갑니다 |
| 「이 함수는 왜 이렇게 짰어?」 | 질문 — 카드 없이 답만 받습니다. Audit 탭에는 남습니다 |
| 「앞으로 보고는 세 줄 이내로 해줘」 | 개인 선호로 저장 — 다음 턴부터, 다음 세션에서도 적용됩니다 |
| 「타치코마, 지금 뭐 하고 있어?」 | 리드를 이름으로 부른 것 — 진행 중 작업의 요약으로 답합니다 |

응답 첫 줄이 `[시각 - 타치코마]` 이면 리드가 말하는 것이고, `[시각 - designer]` 처럼 역할명이면 리드가 위임한 전문가의 보고입니다.

### 따라 해 보기

1. 터미널에 Claude Code 프롬프트가 열려 있는지 봅니다. 없으면 풀어 놓은 디렉토리에서 `bin/s9 code`.
2. 한 문장을 칩니다. 예: `이 저장소의 README 를 읽고 세 줄로 요약해줘` — 무엇이든 됩니다. 한 프롬프트에 서로 다른 일이 여럿이면 타치코마가 요청을 나눠 세웁니다.
3. 대시보드 Board 탭을 봅니다 — OPEN 또는 IN-PROGRESS 열에 그 말로 만든 카드가 생겼습니다(제목은 리드가 짧은 명사구로 다듬을 수 있습니다).
4. 카드를 누르면 문서의 Original 에 친 문장이 그대로 있습니다.
5. 이번엔 Terminal 탭에서 — 입력창에 「방금 요청은 어디까지 됐어?」를 치고 Enter. 위쪽 화면에 응답이 이어집니다. 질문이라 카드는 생기지 않습니다.

### 끝내기

카드가 생기는 것을 봤으면 이 카드를 끝내십시오 — 카드를 눌러 문서를 열고 **→ in-progress** → **상태 옮기기**, 이어서 **→ done** → **상태 옮기기**. 카드가 DONE 열로 갑니다(안내 1의 「끝내기」와 같습니다).
